# TUI 设计要求

本文定义 lx-tui 的界面布局、样式 Token、交互与降级规则。第一版布局参照 herdr 做最小实现。

## 总体布局

```text
┌──────────┬─────────────────────────────────┐
│          │ 标签栏                     [exit]│
│  侧栏     ├───────────────────────┬─────────┤
│          │ 主区域（窗格平铺）      │ prompt  │
│          │                       │  右栏    │
└──────────┴───────────────────────┴─────────┘
```

- 固定顺序：侧栏（左，占据全高）、标签栏（横跨主区与 prompt 右栏的顶部）、主区窗格平铺；prompt 右栏在标签栏下方，顶边与底边同主区窗格对齐。
- 第一版允许只有一个窗格，但区域划分必须按多窗格设计；窗格几何由根级 `src/layout.rs`（BSP）计算，区域划分集中在 `ui/layout.rs`。

## 区域职责

- 侧栏：工作区/会话一级导航；支持折叠；激活项使用强调色，不使用整行反白。竖直中线处为 agents 分区表头：无两端竖线的横线与左对齐标题 `Agents`（与顶部 Workspaces 标题同列），右端折叠按钮与面板顶部折叠按钮同列；表头之上为 Workspaces 列表，之下为 agents 分区（占位，当前无内容、不启动进程）；点击折叠后分区内容收为 0 行、表头贴底边框上一行。
- 标签栏：切换当前工作区内的标签；无标签时显示占位文本，不允许留空行；最右端为退出按钮 `[exit]`，贴屏幕右缘，右缘与右栏折叠态按钮对齐，左键单击退出应用。
- 主区域：BSP 平铺窗格；焦点窗格仅通过边框颜色与标题加粗区分。
- prompt 右栏：全局唯一面板（所有标签与工作区共享），承载可编辑的 markdown prompt 文本；不因窄屏隐藏；启动宽度为主区可用宽度的一半（复刻旧 50% 分割），可拖拽调整与折叠；点击聚焦后键盘输入进入编辑器，内容可被选择复制。

## 浮层与模态

- 全局 toast 是非模态反馈：同一时刻只显示一条，新消息替换旧消息；锚点容器内顶边框下方水平居中，容器过窄、缺失或未指定锚点时降级到屏幕顶部居中；绝对定位、不改变底层布局尺寸、不铺自绘背景（`Clear` 后绘制），默认 2 秒自动消失，hover 期间暂停消失，左键点击立即关闭。
- 引入对话框、命令面板等模态浮层时：同一时刻只处于一个模式，浮层出现时保持底层画面可见，`Esc` 可关闭，且不得改变底层布局尺寸。
- 需要确认的破坏性操作（关闭窗格等）必须二次确认。

## 配色与样式

- 样式只从 `ui/style.rs` 的语义函数取用（`text` / `muted` / `accent` / `border`），禁止在组件中直接写死颜色与修饰符。
- 配色沿用 codex：跟随终端原生 ANSI 色——正文使用终端默认前景，次要信息用 `dim`，强调/焦点用 `Cyan` 加粗；状态色沿用 codex 语义（成功 `Green`、失败 `Red`、注意 `Yellow` 仅在已知暗色终端使用）。
- markdown 高亮沿用 ANSI 槽位与修饰符（同步 lx-agent 的色彩语义，不做 RGB 与背景）：语法标记为 `dim`，标题/粗体 `Yellow` 加粗，斜体 `Yellow` 斜体，删除线 `LightRed` 加删除线，行内代码 `LightRed`，代码块内容保持默认前景（不做语言级 token 着色），引用 `LightMagenta` 斜体，链接文字 `LightBlue` 下划线、URL `Cyan`；映射集中在 `ui/style.rs` 的 markdown 语义函数。
- 不铺自绘背景，保持终端透明；不使用 RGB、渐变、阴影或动画。
- 明暗终端均须可读：不得使用暗灰等只在单一背景色下可读的前景，`dim` 的对比度交给终端保证。
- 无主题切换；如需差异化外观，优先调整终端自身配色。浮层使用 `Clear` 重置底层内容后绘制。

## 窗格内容

- 窗格内运行真实 PTY 进程（默认 `$SHELL`），终端仿真用 `alacritty_terminal`（纯内存），渲染只读网格。
- 焦点窗格显示光标（反显）；隐藏光标由程序模式决定。
- 宽字符占位单元格必须标记为 diff 跳过，禁止渲染出半个字符。
- 窗格标题优先使用程序通过 OSC 设置的标题，否则回退为 `pane N`；进程退出后标题追加 `(exited)`，保留最后一屏。
- 终端模式（DECCKM、括号粘贴等）决定按键与粘贴编码，编码集中在 `input/encode.rs`。
- `placeholder` 窗格为空占位：不启动 PTY、无内容，标题沿用 `pane N`。
- prompt 右栏是独立于终端仿真的 markdown 编辑器（不启动 PTY）：点击聚焦并定位光标，支持字符/换行、退格/删除、方向键/Home/End、readline 编辑键（`Ctrl+U/K` 删除到逻辑行首/尾、`Ctrl+W`/`Ctrl+Backspace` 向前删词、`Ctrl+Delete`/`Alt+D` 向后删词、`Ctrl+A/E` 逻辑行首/尾、`Ctrl+D` 正向删除、`Ctrl+←/→` 与 `Alt+B/F` 按词移动）、撤销/重做（`Ctrl+Z`/`Ctrl+Y`，并接受 `Ctrl+Shift+Z`、`Ctrl+-`、`Ctrl+.` 与 `Super` 组合；快照历史上限 200 步，连续输入/退格合并为一步）、`Tab`/`Shift+Tab` 按 2 空格缩进单位整体缩进/反缩进、以及系统粘贴（`\t` 按 2 空格展开）；列表按 Enter 续写（无序/有序/任务标记，序号 +1，嵌套缩进延续，空项退出层级），紧跟列表标记的 Backspace 先将标记替换为等宽空格，围栏代码块内以上行为还原为普通文本编辑；软换行排版，滚轮每次滚动 3 个视觉行（光标不动，下次按键或点击吸回），键盘编辑后纵向滚动跟随光标；聚焦时边框用强调色并显示光标反显，点击终端窗格或折叠后失焦；未映射按键（`Ctrl+C`、翻页键、`Shift` 选择等）在聚焦时一律吞掉，不写入任何 PTY；不做格式化命令。
- 左右栏均可折叠：展开态在顶边右端显示折叠按钮，左栏为 `[◀]`、右栏为 `[▶]`（紧挨标题）；折叠后压缩为 4 列窄条（3 个内容列 + 1 列贴主区一侧的分隔线，左栏在右缘、右栏在左缘），条内不显示文字内容，仅在顶行内容区水平居中显示反向箭头标签（左栏 `[▶]`、右栏 `[◀]`，恰好占满 3 个内容列）；箭头指向点击后的移动方向；按钮使用强调色以区别于普通文字，仅通过鼠标点击切换；右栏折叠期间分割线不可拖拽，展开恢复折叠前宽度。

## 交互

- 应用级快捷键只保留 `Ctrl+Q` 退出（prompt 聚焦时同样生效）；prompt 聚焦时其余按键映射为编辑器命令（readline 与列表编辑子集），未映射按键吞掉；其余情况按键（含 `Ctrl+C`、`Tab`）一律原样编码进焦点窗格，不存在前缀状态机与应用键位。
- 鼠标承担全部交互：点击 prompt 内容区聚焦编辑器并定位光标，滚轮悬停在 prompt 上时按 3 个视觉行滚动其视口（拖拽选区期间不滚动）；点击终端窗格聚焦该窗格并收回 prompt 焦点；左右栏顶边与 agents 表头的折叠按钮分别切换对应面板/分区；标签栏右端的退出按钮单击退出应用；主区与 prompt 右栏之间的分割线支持拖拽调整右栏宽度。
- Unix 用显式 VT 序列上报按键/释放/拖动/移动（SGR 1000/1002/1003/1006），Windows 走 crossterm 的 WinAPI 捕获；移动上报仅用于分割线悬停反馈。
- 分割线只命中相邻两列边框（主区最右窗格右边框、右栏左边框），不侵入内容区；顺序执行折叠按钮命中优先；拖拽与文本选择互斥，按下清选区、松开只结束拖拽且不写剪贴板。
- 悬停或拖拽分割线时，两列边框改为强调色；同时通过 OSC 22 把鼠标指针设为 `ew-resize`，离开显式发 `default` 恢复（空 payload 部分终端不认，不支持的终端静默忽略、高亮兜底）。
- 右栏宽度拖拽与窗口缩放都保证两侧不小于最小宽度（`min_pane_width`，默认 10 列，含边框）；可用宽度不足两个最小值时均分。

## 选择与复制

- 终端窗格与 prompt 编辑器支持文本选择；空占位窗格没有内容，不参与选择。
- 交互：左键按下即定位光标并锚定选择，拖动实时反显高亮且光标跟随释放点，松开时非空选区写入系统剪贴板并清除选区（空选区仅保留点击定位的光标、不提示）；写入结果通过全局 toast 在选区所在窗格反馈（成功 `Copied to clipboard`、失败 `Copy failed`）。
- 终端文本提取交给终端仿真器（`alacritty_terminal` 的 Selection），宽字符、换行与行尾空格由其处理；选择范围仅限当前视口。
- prompt 选区按渲染后的视口行列坐标映射回文本字节偏移，软换行连续行不插入换行、宽字符整字命中；松开时提取原文写入剪贴板。
- 剪贴板写入（参考 opencode）：OSC 52 立即写（tmux/screen 自动加 passthrough 包装）；原生工具（macOS `pbcopy`、Windows PowerShell `Set-Clipboard`、Linux `wl-copy`/`xclip`/`xsel`）在后台线程限时执行，绝不阻塞事件循环；OS 代码只出现在 `src/platform/`。
- 高亮使用终端原生反显（REVERSED），不引入自绘背景或主题色。
- 按键路由集中在 `input/`，组件内禁止散落按键判断。
- 交互反馈自然克制；不得因 hover、文案或 loading 改变既有布局尺寸。

## 尺寸与降级

- 最小可用尺寸 40x10，低于时显示尺寸提示并等待终端恢复。
- 宽度不足 80 列时隐藏左栏（右栏保留）；宽度充足时左右栏均可折叠为 4 列窄条。
- 窗格与右栏尺寸变化时同步更新终端网格与 PTY 窗口尺寸。
- 退出、panic、收到终止信号时必须还原鼠标指针形状、还原光标、关闭括号粘贴、清理全部鼠标上报模式、恢复终端原始模式，并在等待在途上报后清空输入队列（防止鼠标序列泄漏进 shell）。

## 组件使用

- 优先复用 `ui/widgets/` 组件；确认没有可用组件后再新增，或直接组合 ratatui 原语。
- 无业务语义的组件不得依赖 `app` 领域数据。
