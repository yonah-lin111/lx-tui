# TUI 设计要求

本文定义 lx-tui 的界面布局、样式 Token、交互与降级规则。第一版布局参照 herdr 做最小实现。

## 总体布局

```text
┌──────────┬─────────────────────────────────┐
│          │ 标签栏                     [exit]│
│  侧栏     ├───────────────────────┬─────────┤
│          │ 主区域（窗格平铺）      │ prompt  │
│          │                       │  右栏    │
└──────────┴───────────────────────┴─────────┘
```

- 固定顺序：侧栏（左，占据全高）、标签栏（横跨主区与 prompt 右栏的顶部）、主区窗格平铺；prompt 右栏在标签栏下方，顶边与底边同主区窗格对齐。
- 第一版允许只有一个窗格，但区域划分必须按多窗格设计；窗格几何由根级 `src/layout.rs`（BSP）计算，区域划分集中在 `ui/layout.rs`。

## 区域职责

- 侧栏：工作区/会话一级导航；支持折叠；激活项使用强调色填充（青底黑字），鼠标悬停的非激活项使用终端原生反显（`style::selection`，同右键菜单选中项），其余项不使用整行反白，也不使用背景色。竖直中线处为 agents 分区表头：无两端竖线的横线与左对齐标题 `Agents`（与顶部 Workspaces 标题同列，标题用与其他边框标题一致的 `style::border_title` 淡蓝色），右端折叠按钮与面板折叠按钮同列；表头之上为 Workspaces 列表，之下为 agents 分区（占位，当前无内容、不启动进程）；点击折叠后分区内容收为 0 行、表头贴底边框上一行。侧栏顶边框右端（原折叠按钮位置，距右边框 1 列）为新建按钮 `[+]`：点击立即创建并激活单窗格 `shell` 工作区，目录取当前工作区焦点终端窗格的实时 cwd（回退该工作区主终端 cwd、进程 cwd），名字取目录末段（HOME 显示 `~`、根路径显示完整路径），与现有工作区重名时追加最小未用序号；工作区路径与 git 归属在创建时确定后保持不可变，不随窗格内 `cd` 漂移（窗格各自跟踪 cwd，仅用于标题与新建工作区取目录）。启动时创建的工作区在名字后显示不可移除的 `*` 标记（表示最初进入的路径，颜色随行内正文样式，不做独立着色），名字超宽先截断以保证标记可见。工作区按 cwd 识别 git checkout 元数据（`git worktree list --porcelain`，后台查询）：同一仓库有 ≥1 个 linked worktree 且含非 linked 主项时成组，树根固定为创建最早的非 linked 主项（按根窗格标识序，拖拽换位不改变）；顶层项（组父项、重复主 checkout 与非 git / 未分组工作区）统一缩进 2 列、名字同列，根之后（索引更大）的 linked worktree 项在缩进列用 `├─ ` / `└─ ` 树形连接符（末位按可见子项判定）并显示分支短名（去掉 `worktree/` 前缀）作标签；同一组内 linked 标签重复时在名字后追加最小未用序号（2、3…，含被折叠隐藏的子项保持稳定），`*` 标记排在其后，手动命名的工作区仍显示自定义名。组父项行在左缘显示折叠箭头（`▾ ` 展开 / `▸ ` 折叠，accent 色，占 2 列），父项名字与子项连接符同列，仅点击箭头格切换折叠，父项行其余区域仍为切换工作区与拖动；折叠后仅保留父项与当前激活子项，折叠状态按仓库根路径仅存内存（重启恢复展开）；列表不做父项前置重排，渲染、命中与滚动按可见行映射（被隐藏的子项不可点击/拖动）。打开 linked worktree 时（Open 对话框、启动 cwd、`[+]` 新建首次识别到元数据）若其仓库主 checkout 尚未打开，自动在该仓库首个成员之前插入主工作区（shell 在主 checkout 启动），保证树形结构始终成立。列表项左键单击切换当前工作区（右侧 prompt 随之切到该工作区草稿；钉住时保持不变），按住上下拖动可实时重排：被拖项所在组（根 + linked 子项，折叠隐藏的子项同样跟随）整体移动，指针移动后组内可见行整行反显（按下未移动不反显，直接显示整行选中态，保证单击切换一次成型），重复主 checkout 独立单项移动，落点落在别的组上吸附到该组上/下边界（不插进组中间）；松手完成，激活项与 `*` 标记跟随条目移动；仅支持可视范围内排序，不做边缘自动滚动，右键弹出菜单（`New terminal` / `Open prompt` / `Rename` / `Open worktree` / `Close`；`New terminal` 在目标工作区追加直接进入终端视图的标签并以该工作区固定路径启动；`Open prompt` 展开并聚焦 Prompt 且切换激活该工作区；`Open worktree` 仅当该工作区已有 git 元数据时显示，`Close` 仅剩一个工作区时不显示）；列表溢出时右缘一列显示滚动条（滚轮每格 1 项、轨道点击跳转、拖拽 thumb），创建/切换/关闭后自动保证当前项可见。侧栏展开宽度可拖拽调整：最小 18 列、最大 40 列，且不把主区挤到小于最小窗格宽度；折叠态不可拖拽。
- 标签栏：切换当前工作区内的标签；标签标题未重命名时按位置动态显示 `tab N`（关闭后自动重新编号），重命名后显示自定义名；激活标签使用强调色填充（青底黑字，不含尾部竖线分隔符），鼠标悬停的非激活标签使用终端原生反显（同样不含分隔符），其余标签保持 muted；左键单击标签切换（清除选区、收回 prompt 焦点）；每个标签后紧跟竖线分隔符。最后一个标签之后为新建按钮 `[+]`（强调色）：左键单击立即新建并激活一个标签（不弹命名框），PTY 按状态对齐启动；标签总宽超出可视区时自动切换为滚动布局：左端 `[<]`、`[+] [>]` 依次贴退出按钮左侧，标签按完整标签宽度逐格滚动，不可滚方向按钮置灰，未溢出时不显示滚动按钮；新建/切换/关闭标签、切换工作区或窗口缩放后自动保证激活标签完整可见。右键标签弹出菜单 `New tab / Rename / Close`（仅剩一个标签时不显示 `Close`），`New tab` 立即新建并激活，`Rename` 弹出重命名浮层预填当前标题，`Close` 弹出二次确认；标签重命名/关闭操作与工作区同名规则一致。最右端为退出按钮 `[exit]`，贴屏幕右缘，右缘与右栏折叠态按钮对齐，左键单击退出应用。
- 主区域：BSP 平铺窗格；每个窗格的主内容有 lx 欢迎页与终端两个互斥视图（默认 lx）。窗格顶边框右端为切换按钮：终端视图显示 `[lx]`、lx 视图显示 `[>_]`（显示点击后的目的地，对齐折叠按钮的方向语义），纯鼠标点击且不改变焦点，窗格过窄时隐藏。标题随视图变化：lx 页显示 `lx`，终端视图沿用 OSC → cwd → `pane N`，两者都追加退出后缀。焦点窗格仅通过边框颜色区分（标题与其余面板统一淡蓝色）。窗格内容区（终端与 lx 视图）右键弹出窗格菜单：`Split right` / `Split down` / 按当前视图动态显示 `Switch to terminal` 或 `Switch to lx` / `Open prompt` / `Switch to ws path`（仅当所属工作区有固定路径时显示，经二次确认向窗格写入转义后的 `cd` 命令回到工作区路径） / `Close`（仅剩一个窗格时不显示 `Close`）；分割作用于被右键窗格、新窗格继承其视图并获得焦点且右键不改变焦点，`Close` 经二次确认后删除窗格并把焦点交给提升兄弟子树的树序首个窗格。
- lx 视图的键鼠与动画：除 `Ctrl+Q` 外按键与粘贴一律吞掉，不写入后台 PTY；内容区鼠标仅保留点击聚焦，不启动终端选区、不转发鼠标上报、不显示滚动条且忽略滚轮。切回终端视图时 PTY 会话、画面与回滚位置原样保留。lx 页是纯展示的欢迎页，模仿 Claude Code 的信息层级：顶部完整狐狸像素画（18×7，摆尾/眨眼/抖耳，仅可见时按 200ms 推进相位，右侧不显示字标）、中部白色占位面板（未来内容区，Indexed 231）、底部输入框（纯视觉占位，`>` + `Ask anything…`）与切换提示；空间不足或宽度画不出完整狐狸时，自下而上依次省略提示、占位面板与品牌区，最小退化为居中 `lx` 字标。未来接入 agent 消息内容时切换为不含狐狸的内容视图。
- prompt 右栏：全局唯一面板（所有标签与工作区共享），承载可编辑的 markdown prompt 文本；边框标题左侧为 `Prompt`，顶边框右侧为 `ws:路径末段名`（优先 Prompt 显式绑定根路径，回退 checkout 路径与工作区 cwd，无路径时不显示；前缀强调色、值 muted，与底边框 `b:` 一致）；不因窄屏隐藏；启动宽度为主区可用宽度的 2/5（主区更宽，不与 prompt 对半），可拖拽调整与折叠；点击聚焦后键盘输入进入编辑器，内容可被选择复制。工作区或窗格菜单的 `Open prompt` 会在折叠时自动展开并聚焦，并把绑定根切到工作区路径或该窗格当前 cwd（提及扫描与顶栏路径名随之切换；未显式绑定时回退活动工作区 cwd）。内容区顶部 2 行为固定工具栏（不随文本滚动）：首行左侧 `[undo]` `[redo]`（无历史时置灰、点击不抢焦点），右侧 `[select all]`（内容区宽度 < 28 列时隐藏）与保存状态点（已保存绿 `●` / 未保存黄，点击复位为已保存；任何文本修改置未保存）；`[select all]` 生成覆盖全文的选区而非直接写剪贴板；次行为贯穿的 `─` 分割线，两端以 `├` / `┤` 衔接边框，样式跟随边框焦点态（聚焦强调色、失焦 muted）。底边框左侧嵌入激活工作区的 git 状态（零额外行高）：`b:主 checkout 分支`（linked worktree 显示仓库主分支，主 checkout 显示自身分支），linked worktree 追加 ` wt:工作区名`；非 git 不显示，右端避让折叠按钮。内容区高度不足以容纳表头或折叠态时不渲染工具栏与状态。

## 浮层与模态

- 浮层（toast、右键菜单、命令面板、模态容器）统一铺自包含面板底色：`ui/style.rs` 的 `overlay_panel`（Indexed 236 底、Indexed 252 字），整块含边框不透明，透明终端下不透视底层；浮层内选中/悬停项先重置为终端默认前景/背景再反显（`overlay_selection`），不受面板底色影响。
- 全局 toast 是非模态反馈：同一时刻只显示一条，新消息替换旧消息；锚点容器内顶边框下方水平居中，容器过窄、缺失或未指定锚点时降级到屏幕顶部居中；绝对定位、不改变底层布局尺寸，默认 2 秒自动消失，hover 期间暂停消失，左键点击立即关闭。边框用语义色，标题以 muted 显示在顶边框（复制反馈为 `Clipboard`），正文居中占一行。
- 引入对话框、命令面板等模态浮层时：同一时刻只处于一个模式，浮层出现时保持底层画面可见，`Esc` 可关闭，且不得改变底层布局尺寸。
- 右键菜单：锚点定位并夹取屏幕内；顶边框显示 muted 标题（工作区名 / 标签名 / 窗格标题，取不到时回退 `workspace` / `tab` / `pane`）；`Esc` 关闭、`↑/↓` 循环移动高亮、`Enter` 执行当前项、鼠标悬停跟随高亮、点击菜单外关闭且不穿透；打开期间接管键盘，其余按键一律不写入 PTY。
- 重命名浮层：居中模态；预填当前名字、光标在末尾；底部按钮 `[save enter] [clear ^c] [cancel esc]`（名称在前、快捷键在后），按钮可点击；`Enter` 保存（trim 后为空则拒绝且浮层保持打开）、`Esc` 取消、`Ctrl+C` 清空输入；点击弹窗内非按钮区域或弹窗外取消；硬件光标与输入位置同步，视口与光标按显示宽度滚动（宽字符按两列计，与 prompt 编辑器一致）。
- 关闭确认浮层：居中模态；问题行 + 底部按钮 `[confirm enter] [cancel esc]`；`Enter` 确认、`Esc` 或点击弹窗内非按钮区域取消；确认后终止该工作区全部 PTY 并移除，关闭当前工作区时焦点落到同索引、越界回退末项；至少保留一个工作区。
- 切换工作区路径确认浮层：居中模态；问题行完整展示目标路径（弹窗宽度随路径展开，仅在超出屏幕时夹取），底部按钮 `[confirm enter] [cancel esc]`；确认后向目标窗格写入转义并双引号包裹的 `cd "路径"` 命令（保留用户 Shell 环境变量与历史），`Esc` 或点击弹窗内非按钮区域取消。
- 右键菜单与模态尺寸按终端显示列（`UnicodeWidthStr::width`）计算，正常窗口下菜单项与标题完整显示、不做省略，仅在物理宽度不足时夹取到屏幕宽度。
- worktree 对话框：居中模态；顶部搜索行（占位 `filter worktrees`，输入即过滤名字/目录名/路径/状态，不区分大小写）、分隔线、两行条目（上行 `› 分支名或目录名` + 右对齐状态 `open` / `detached` / `root`，下行缩进路径）与底部按钮 `[open enter] [cancel esc]`；`↑/↓` 在过滤结果内移动（不循环），`Enter` / `[open]` 打开选中项（已作为工作区打开时直接切换、不重复创建；否则以该 checkout 为 cwd 新建工作区并带入 git 元数据），`Esc` / `[cancel]` / 点击弹窗外关闭；条目点击高亮，加载中显示 `loading…`、失败显示 `failed to list worktrees`、空列表显示 `no worktrees found`；列表查询在后台执行，不阻塞事件循环。
- 需要确认的破坏性操作（关闭窗格等）必须二次确认。

## 配色与样式

- 样式只从 `ui/style.rs` 的语义函数取用（`text` / `muted` / `accent` / `border` / `selected_item` / `selection` / `overlay_panel` / `overlay_selection`），禁止在组件中直接写死颜色与修饰符。
- 面板边框标题统一用 `style::border_title`（淡蓝色：Cyan + dim、不加粗，与分支状态同色系；焦点/浮层的强调色边框不改变标题观感），覆盖侧栏、窗格、prompt、toast、右键菜单与模态弹窗；按钮（折叠按钮、视图切换按钮、prompt 工具栏按钮、`[exit]`、`[+]` 等）保持强调色。
- 配色沿用 codex：跟随终端原生 ANSI 色——正文使用终端默认前景，次要信息用 `dim`，强调/焦点用 `Cyan` 加粗；状态色沿用 codex 语义（成功 `Green`、失败 `Red`、注意 `Yellow` 仅在已知暗色终端使用）。
- markdown 高亮沿用 ANSI 槽位与修饰符（同步 lx-agent 的色彩语义，不做 RGB 与背景）：语法标记为 `dim`，标题/粗体 `Yellow` 加粗，斜体 `Yellow` 斜体，删除线 `LightRed` 加删除线，行内代码 `LightRed`，代码块内容保持默认前景（不做语言级 token 着色），引用 `LightMagenta` 斜体，链接文字 `LightBlue` 下划线、URL `Cyan`；映射集中在 `ui/style.rs` 的 markdown 语义函数。
- 默认不铺自绘背景，保持终端透明；不使用 RGB、渐变、阴影或动画。例外一：侧栏/标签栏选中行的整行背景（仅 ANSI-16 的 `Cyan`，经 `ui/style.rs` 的 `selected_item` 取用）；悬停行使用终端原生反显（`selection`，同右键菜单选中项），不引入自绘背景。例外二：lx 页吉祥物像素画使用 256 色 Indexed 调色板（仅经 `ui/style.rs` 的 `mascot_pixel` / `lx_placeholder` 取色）与 200ms 帧动画，其余区域维持原规则。例外三：四类浮层（toast、右键菜单、命令面板、模态容器）的整块面板底色（仅经 `ui/style.rs` 的 `overlay_panel` 取用：Indexed 236 底、252 字）。
- 光标统一使用终端原生硬件光标（不自绘反显块），且 TUI 运行期间关闭闪烁、保持终端配置的光标形状：进入时下发 DEC 私有模式 12（`\x1b[?12l`），退出恢复（`\x1b[?12h`），不支持的终端静默忽略。原因是动画/高频重绘会重置部分终端（Ghostty 等）的光标闪烁相位，硬件光标的闪烁无法在重绘下稳定维持，只能整体关闭。同一时刻只有一个硬件光标（优先级：浮层输入 > prompt 编辑器 > 焦点窗格），单行输入（如重命名）与多行编辑器共用同一套显示宽度光标/视口规则。高频重绘（如 lx 页动画）不得每帧重复下发光标指令：`tui/` 的光标去重后端只在可见性变化时下发 Hide/Show，只在内容 diff 可能移动物理光标或目标位置变化时下发 MoveTo。
- 帧提交使用终端同步更新（DEC 2026）：每帧以 `BeginSynchronizedUpdate` / `EndSynchronizedUpdate` 包裹提交，支持该模式的终端整帧原子呈现（选中/hover 背景切换不会逐格涂抹）；不支持的终端静默忽略、保持原绘制路径。
- 明暗终端均须可读：不得使用暗灰等只在单一背景色下可读的前景，`dim` 的对比度交给终端保证。
- 无主题切换；如需差异化外观，优先调整终端自身配色。浮层使用 `Clear` 重置底层内容后绘制。

## 窗格内容

- 窗格内运行真实 PTY 进程（默认 `$SHELL`），终端仿真用 `alacritty_terminal`（纯内存），渲染只读网格。shell 按窗格所属工作区的 cwd 启动：打开 worktree 的工作区即为该 checkout，分割窗格与新标签继承工作区跟踪到的当前目录。
- 焦点窗格把硬件光标同步到仿真光标处（IME 预输入与候选随硬件光标显示），显示与闪烁由终端原生光标承担；隐藏光标由程序模式决定，失焦、程序隐藏或光标滚出视口时硬件光标一并隐藏。
- 宽字符占位单元格必须标记为 diff 跳过，禁止渲染出半个字符。
- 窗格标题优先使用程序通过 OSC 设置的标题（claude code、codex 等程序依赖该通道）；未设置 OSC 标题时显示该窗格 shell 进程 cwd 的标签（复用工作区命名规则：HOME 显示 `~`、根路径显示完整路径、其余取末段），读不到 cwd 时回退为 `pane N`；进程退出后标题追加 `(exited)`，保留最后一屏。
- 终端模式（DECCKM、括号粘贴等）决定按键与粘贴编码，编码集中在 `input/encode.rs`。
- `placeholder` 窗格为空占位：不启动 PTY、无内容，标题沿用 `pane N`。
- prompt 右栏是独立于终端仿真的 markdown 编辑器（不启动 PTY）：草稿按工作区隔离，每工作区各持一份编辑器状态（文本/撤销/选区/@ 面板/显式上下文根），切换工作区即切换到该工作区草稿，在途 @ 扫描结果按编辑器标识路由回所属草稿；点击聚焦并定位光标，支持字符/换行、退格/删除、方向键/Home/End、readline 编辑键（`Ctrl+U` 删除到逻辑行首、已在行首时删除前一个换行并合并上一行，`Ctrl+K` 删除到逻辑行尾、`Ctrl+W`/`Ctrl+Backspace` 向前删词、`Ctrl+Delete`/`Alt+D` 向后删词、`Ctrl+A/E` 逻辑行首/尾、`Ctrl+D` 正向删除、`Ctrl+←/→` 与 `Alt+B/F` 按词移动）、撤销/重做（`Ctrl+Z`/`Ctrl+Y`，并接受 `Ctrl+Shift+Z`、`Ctrl+-`、`Ctrl+.` 与 `Super` 组合；快照历史上限 200 步，连续输入/退格合并为一步）、`Ctrl+Enter`/`Cmd+Enter`（`Shift+Enter` 在 @ 面板未打开时同样）在当前逻辑行尾另起一行并保留行首缩进（不续写列表标记）、`Tab`/`Shift+Tab` 按 2 cwd）并尊重 `.gitignore`（跳过隐藏目录与 `node_modules` 等重目录，缓存随根路径变化失效）；面板高度不超过容器（prompt 内容区）的一半，随光标位置在视口内上下自适应；条目双行展示（上行为 muted 的目录/文件图标（标准单宽符号 `▸` / `•`）加文件名、目录带 `/`，下行为 `└─ ` 前缀的父目录，超出面板宽度时按显示列中间截断（保留路径首尾与 `…`，对齐 opencode）；无父目录时单行），超出可见范围时面板内右缘显示滚动条（样式同 prompt：轨道 muted、thumb accent），鼠标滚轮只滚动面板视口（视口到底/顶后钳制不循环，高亮原地不动、可被滚出视口）、键盘 `↑/↓` 循环移动高亮（窗口跟随高亮滚动），鼠标悬停只移动高亮、不滚动窗口（窗口仅随键盘与滚轮移动），`Enter` 或左键点击插入 `@相对路径 `（目录带 `/`）、`Esc` 关闭、失焦或折叠时收起；面板顶边左侧显示 muted 标题 `Files`，进入文件夹后顶边右侧显示该目录末段名，底边左侧显示 `[open ⇧↵] [back ^z]`（块命令面板顶边左侧同样显示 muted 标题 `Commands`）；`Shift+Enter` 进入高亮目录（仅目录且扫描缓存中存在其后代，高亮为文件或无子项目录时吞掉不动作；把目录根相对路径写回为 `@路径/`，面板按该前缀限定候选——空过滤词只列直接子项，继续输入在该子树内递归模糊匹配，进入后高亮回到首项），回退上一级用编辑器撤销（`Ctrl+Z` / `Cmd+Z`）：进入目录写回作为一步独立可撤销编辑，撤销一次即回上一级（`@src/ui/` → `@src/` → `@`），不设专用返回键；光标紧跟提及后的空白时 Backspace 一次删除整段 `@提及 `（对齐 lx-agent）；软换行排版，文本区固定预留最右 1 列作滚动条槽（文本按槽左宽度换行，滚动条出现/消失不改变换行），文本溢出视口时槽内显示滚动条（样式与 workspaces 一致：轨道 muted、thumb accent；轨道点击跳转、拖拽 thumb 实时滚动，按下滚动条不改变焦点、不移动光标）；滚轮每次滚动 3 个视觉行（光标不动，下次按键或点击吸回），键盘编辑后纵向滚动跟随光标；鼠标拖选按内容行记录锚点（视口滚动时高亮不漂移），拖到视口上/下边缘 3 行内自动滚动并延伸选区（越靠近边缘越快、到边界停止，松开鼠标结束），拖选期间滚轮同样滚动视口并延伸选区；聚焦时边框用强调色，并把硬件光标同步到编辑器光标处（IME 预输入与候选随硬件光标显示，失焦或光标滚出视口时隐藏）；点击终端窗格或折叠后失焦；未映射按键（翻页键、`Shift` 选择等）在聚焦时一律吞掉，不写入任何 PTY；不做格式化命令。内容区顶部固定 2 行工具栏（按钮行 + 分割线），文本视口与滚动条槽整体下移且不覆盖工具栏；点击工具栏或分割线空白吞掉点击，不聚焦文本视口、不移动文本光标；底边框左侧显示面板所属工作区（钉住目标或激活）的 `b:主 checkout 分支`（linked worktree 显示仓库主分支）与 linked worktree 的 ` wt:工作区名`；底边框右端折叠按钮左侧为钉住按钮（未钉 `[pin]`、已钉 `[unpin]`，accent、仅鼠标点击，折叠态不显示）：钉住后切换工作区不改变面板显示，仅在再点按钮、显式 `Open prompt`（工作区/窗格菜单）或被钉工作区被关闭时释放，释放后显示激活工作区草稿；顶栏路径名与 @ 扫描根回退同样取显示中工作区；行首输入 `/` 打开模板命令面板（`Templates` 标题，短名 `/add` 等，短名与长别名双向匹配，并按 @ 面板同款分层打分支持子序列模糊匹配（`/cmm` → `/common`）；围栏与模板块内抑制）：回车整行插入标准 `&&& <name>Template --start` + 次行行首 `「title: 」` + 正文 + `&&& <name>Template --end` 模板块（标题占位符独立成行，避免与起止行标记、操作按钮挤在同一行；单步撤销），光标落在标题占位符内；模板块按状态渲染边框与整块底色（todo 靛蓝边框 + 藏青底 / in_progress 黄边框 + 暗琥珀底 / done 绿边框 + 暗绿底，256 色暗色调，选区反显格不铺底），起始行右端常显 `[todo]`/`[run]`/`[done]`、`[copy]`、`[clean]`、`[del]` 按钮（左侧内容超出以 `…` 截断，按钮不因窄屏隐藏），`[clean]` 清理未填空项、`[del]` 删除整块、状态按钮循环切换均为单步可撤销编辑，`[copy]` 按 lx-agent 复制语义提取正文（剔除标题占位行、`+++` 补充子块及其内容、保留 `%%%` 记录子块内容但剔除其标记行、剔除 `//` 注释行与未填写空项）并 toast 反馈；`Ctrl/Cmd+Shift+C` 复制光标所在模板块的同一份正文（不在块内不动作）。标题占位符用 Cyan 下划线（与状态色边框、@ 提及黄区分）。
- 左右栏均可折叠：展开态在底边右端显示折叠按钮，左栏为 `[◀]`、右栏为 `[▶]`；折叠后压缩为 4 列窄条（3 个内容列 + 1 列贴主区一侧的分隔线，左栏在右缘、右栏在左缘），条内不显示文字内容，仅在底行内容区水平居中显示反向箭头标签（左栏 `[▶]`、右栏 `[◀]`，恰好占满 3 个内容列）；箭头指向点击后的移动方向；按钮使用强调色以区别于普通文字，仅通过鼠标点击切换；左右栏折叠期间各自分割线不可拖拽，展开恢复折叠前宽度。

## 交互

- 应用级快捷键只保留 `Ctrl+Q` 退出（prompt 聚焦与浮层打开时同样生效）；浮层打开时按键按浮层种类过滤（菜单 `Esc/↑/↓/Enter`、重命名 `Esc/Enter` 与单行编辑键、确认 `Esc/Enter`），其余吞掉；prompt 聚焦时其余按键映射为编辑器命令（readline 与列表编辑子集），未映射按键吞掉；其余情况按键（含 `Ctrl+C`、`Tab`）一律原样编码进焦点窗格，不存在前缀状态机与应用键位。
- 鼠标承担全部交互：点击 prompt 内容区聚焦编辑器并定位光标，滚轮悬停在 prompt 上时按 3 个视觉行滚动其视口（拖拽选区期间不滚动）；点击终端窗格聚焦该窗格并收回 prompt 焦点；左右栏底边与 agents 表头的折叠按钮分别切换对应面板/分区；标签栏右端的退出按钮单击退出应用；主区与 prompt 右栏之间、侧栏与主区之间的分割线均支持拖拽调整对应栏宽；左键单击侧栏工作区项切换工作区（清除选区、收回 prompt 焦点），右键工作区项打开菜单；滚轮悬停在 workspaces 区滚动工作区列表（每格 1 项），滚动条轨道可点击跳转、thumb 可拖拽；浮层打开期间鼠标点击只作用于浮层，不穿透底层。
- Unix 用显式 VT 序列上报按键/释放/拖动/移动（SGR 1000/1002/1003/1006），Windows 走 crossterm 的 WinAPI 捕获；移动上报仅用于分割线悬停反馈。
- 分割线只命中相邻两列边框（主区最右窗格右边框、右栏左边框），不侵入内容区；顺序执行折叠按钮命中优先，prompt 滚动条槽命中优先于编辑器点击；拖拽与文本选择互斥，按下清选区、松开只结束拖拽且不写剪贴板。
- 悬停或拖拽分割线时，两列边框改为强调色；同时通过 OSC 22 把鼠标指针设为 `ew-resize`，离开显式发 `default` 恢复（空 payload 部分终端不认，不支持的终端静默忽略、高亮兜底）。
- 右栏宽度拖拽与窗口缩放都保证两侧不小于最小宽度（`min_pane_width`，默认 10 列，含边框）；可用宽度不足两个最小值时均分。

## 选择与复制

- 终端窗格与 prompt 编辑器支持文本选择；空占位窗格没有内容，不参与选择。
- 交互：左键按下即定位光标并锚定选择，拖动实时反显高亮且光标跟随释放点；终端窗格松开时非空选区写入系统剪贴板并清除选区（空选区与全空白选区视为无可复制内容，仅清除选区、不提示），写入结果通过全局 toast 在选区所在窗格反馈（成功 `Copied to clipboard`、失败 `Copy failed`）；prompt 松开后保留选区高亮，按 `Ctrl/Cmd+C` 复制：有选区复制选区原文，无选区复制全文（同样 toast 反馈；内容为空不提示），`Ctrl/Cmd+Shift+C` 复制光标所在模板块正文（对齐 lx-agent 的 `Mod-Shift-C`；legacy 终端不区分 Shift 时退化为普通复制），滚轮滚动其视口、折叠或尺寸变化时清除选区。
- 终端文本提取交给终端仿真器（`alacritty_terminal` 的 Selection），宽字符、换行与行尾空格由其处理；选择范围仅限当前视口。
- prompt 选区按渲染后的视口行列坐标映射回文本字节偏移，软换行连续行不插入换行、宽字符整字命中；复制时提取原文写入剪贴板；有选区时输入类按键用新内容替换选区、`Backspace`/`Delete` 删除选区（一次撤销即可恢复），其余编辑命令先清除选区。
- 剪贴板写入（参考 opencode）：OSC 52 立即写（tmux/screen 自动加 passthrough 包装）；原生工具（macOS `pbcopy`、Windows PowerShell `Set-Clipboard`、Linux `wl-copy`/`xclip`/`xsel`）在后台线程限时执行，绝不阻塞事件循环；OS 代码只出现在 `src/platform/`。
- 文本/列表选区高亮使用终端原生反显（REVERSED）；条目选中背景只允许侧栏与标签栏且收口在 `style.rs` 的 `selected_item`，悬停反显收口在 `selection`。
- macOS 终端默认把 `Cmd+C` 绑到终端自身的复制动作（Ghostty/iTerm2/Terminal.app 均如此）：应用捕获鼠标时终端没有原生选区，该键被吞掉、到不了应用。Ghostty 用 `keybind = performable:super+c=copy_to_clipboard` 即可在无原生选区时把 `Cmd+C` 以 kitty 协议（`CSI 99;9u`）下发给应用；不支持该协议或配置的终端用 `Ctrl+C`（`\x03` / kitty `CSI 99;5u`），应用侧三种输入都已支持。
- 按键路由集中在 `input/`，组件内禁止散落按键判断。
- 交互反馈自然克制；不得因 hover、文案或 loading 改变既有布局尺寸。

## 尺寸与降级

- 最小可用尺寸 40x10，低于时显示尺寸提示并等待终端恢复。
- 宽度不足 80 列时隐藏左栏（右栏保留）；宽度充足时左右栏均可折叠为 4 列窄条。
- 窗格与右栏尺寸变化时同步更新终端网格与 PTY 窗口尺寸。
- 启动时启用 kitty 键盘协议（`DISAMBIGUATE_ESCAPE_CODES`），使 Super/Cmd 组合在支持的终端可达；不支持的终端忽略该私有序列，PTY 路径一律丢弃含 Super 的按键（防止 Cmd+C 漏成 `c`）。macOS 自带 Terminal.app 无法发送 Cmd 组合，只能使用 `Ctrl` 变体。
- 退出、panic、收到终止信号时必须还原鼠标指针形状、还原光标、关闭括号粘贴、清理全部鼠标上报模式、弹出键盘增强、恢复终端原始模式，并在等待在途上报后清空输入队列（防止鼠标序列泄漏进 shell）；恢复顺序为关闭鼠标上报 → drain 在途输入 → 弹出键盘增强 → 离开备用屏并关闭括号粘贴 → `disable_raw_mode()`，不可交换。

## 组件使用

- 优先复用 `ui/widgets/` 组件；确认没有可用组件后再新增，或直接组合 ratatui 原语。
- 无业务语义的组件不得依赖 `app` 领域数据。
- 菜单与模态容器是公共组件：`ui/widgets/menu.rs` 只接收锚点、标题与标签（定位/渲染/命中），`ui/widgets/modal.rs` 只负责居中、清底、边框、标题与按钮行布局，内容由调用方在返回的 inner 上自行绘制；`ui/widgets/scrollbar.rs` 只接收列表矩形与总量/视口/偏移（几何/命中/渲染）。三者均不依赖 `app` 领域数据。
