# TUI 设计要求

本文定义 lx-tui 的界面布局、样式 Token、交互与降级规则。第一版布局参照 herdr 做最小实现。

## 总体布局

```text
┌──────────┬───────────────────────────────┐
│          │ 标签栏                         │
│          ├───────────────────────────────┤
│  侧栏     │                               │
│          │ 主区域（窗格平铺）              │
│          │                               │
│          ├───────────────────────────────┤
│          │ 状态栏                         │
└──────────┴───────────────────────────────┘
```

- 固定顺序：侧栏（左，占据全高）、标签栏（右侧顶部）、主区域（窗格平铺）、状态栏（右侧底部，固定 1 行）。
- 第一版允许只有一个窗格，但区域划分必须按多窗格设计；窗格几何由根级 `src/layout.rs`（BSP）计算，区域划分集中在 `ui/layout.rs`。

## 区域职责

- 侧栏：工作区/会话一级导航；支持折叠；激活项使用强调色，不使用整行反白。
- 标签栏：切换当前工作区内的标签；无标签时显示占位文本，不允许留空行。
- 主区域：BSP 平铺窗格；焦点窗格仅通过边框颜色与标题加粗区分。
- 状态栏：左侧显示上下文状态，右侧显示快捷键提示；溢出时截断右侧提示，不换行。

## 浮层与模态

- 应用状态同一时刻只处于一个模式（普通 / 浮层模态）；禁止用多个独立布尔标志叠加控制浮层。
- 对话框、命令面板、错误提示使用居中浮层；浮层出现时保持底层画面可见。
- `Esc` 必须可以关闭浮层；需要确认的破坏性操作（关闭窗格等）必须二次确认。
- 浮层不得改变底层布局尺寸。

## 配色与样式

- 样式只从 `ui/style.rs` 的语义函数取用（`text` / `muted` / `accent` / `border`），禁止在组件中直接写死颜色与修饰符。
- 配色沿用 codex：跟随终端原生 ANSI 色——正文使用终端默认前景，次要信息用 `dim`，强调/焦点用 `Cyan` 加粗；状态色沿用 codex 语义（成功 `Green`、失败 `Red`、注意 `Yellow` 仅在已知暗色终端使用）。
- 不铺自绘背景，保持终端透明；不使用 RGB、渐变、阴影或动画。
- 明暗终端均须可读：不得使用暗灰等只在单一背景色下可读的前景，`dim` 的对比度交给终端保证。
- 无主题切换；如需差异化外观，优先调整终端自身配色。浮层使用 `Clear` 重置底层内容后绘制。

## 窗格内容

- 窗格内运行真实 PTY 进程（默认 `$SHELL`），终端仿真用 `alacritty_terminal`（纯内存），渲染只读网格。
- 焦点窗格显示光标（反显）；隐藏光标由程序模式决定。
- 宽字符占位单元格必须标记为 diff 跳过，禁止渲染出半个字符。
- 窗格标题优先使用程序通过 OSC 设置的标题，否则回退为 `pane N`；进程退出后标题追加 `(exited)`，保留最后一屏。
- 终端模式（DECCKM、括号粘贴等）决定按键与粘贴编码，编码集中在 `input/encode.rs`。

## 交互

- 键盘优先、鼠标可选；鼠标能完成的操作必须同时有键盘路径。当前版本不启用鼠标。
- 应用动作一律在 `Ctrl+b` 前缀之后生效；未加前缀的按键（含 `q`、`Tab`、`Ctrl+C`）原样编码进焦点窗格。
- 前缀后未绑定的按键被消费，不透传；连按两次前缀向前缀窗格写入字面 `Ctrl+b`。
- 浮层打开时按键只服务浮层；`Esc` 关闭浮层。
- 快捷键映射集中在 `input/`，组件内禁止散落按键判断。
- 交互反馈自然克制；不得因 hover、文案或 loading 改变既有布局尺寸。

## 尺寸与降级

- 最小可用尺寸 40x10，低于时显示尺寸提示并等待终端恢复。
- 宽度不足 80 列时隐藏侧栏；高度不足 20 行时状态栏只保留左侧核心状态。
- 窗格尺寸变化时同步更新终端网格与 PTY 窗口尺寸。
- 退出、panic、收到终止信号时必须还原光标、关闭括号粘贴与终端原始模式。

## 组件使用

- 优先复用 `ui/widgets/` 组件；确认没有可用组件后再新增，或直接组合 ratatui 原语。
- 无业务语义的组件不得依赖 `app` 领域数据。
