# Prompt 补充块折叠设计

状态：已实施。替换此前的「附件栏 + 模态」方案。
日期：2026-10-22。
范围：Prompt 编辑器内 `&&&` 任务块中的闭合 `+++` 补充块。

## 1. 交互

- 每个闭合 `+++` 块在起始行右上角提供折叠按钮：`[▸]` 折叠（默认）、`[▾]` 展开。
- 折叠只隐藏起始行之后的内容（标题、正文、结束标记与 `{wt:}` 绑定行）；起始行保留，
  边框改为 `├─ … ┤` 的自成一行样式，按钮组紧随右侧。
- 点击按钮切换折叠；不修改正文、不置脏、不新增撤销记录。
- `/supplement` 与自定义 `block: supple` 新建的补充块自动展开：光标落在标题内，
  折叠会把标题藏起来。

## 2. 投影与编辑

- 折叠是纯展示状态。`visual_rows` 跳过隐藏行；光标、点击、选区、滚动与滚动条
  共用同一份可见行序，不另维护行号。
- 光标落入隐藏区时归一到起始行行尾；左右与按词移动整块跳过，不逐字符进入。
- 回车：光标在折叠块起始行（行首除外）或隐藏区内时，新行落在整块之后；
  行首回车仍在块前插入空行。除回车外的写入一旦与隐藏区相交，整次拒绝并 Toast
  `Folded supplement; unfold to edit`，正文、选区与撤销历史保持不变。
- 选区复制只拼接可见行；无选区复制全文仍保留全部 `+++`。

## 3. 状态

- `Prompt.expanded_supplements: BTreeSet<usize>`：已展开块起始行行首字节偏移；
  空集合即全部折叠。
- 正文写入统一经 `splice_text` 平移键；撤销快照与 `PromptHistory` 携带同一集合，
  `set_text` 清空。
- 只折叠闭合补充块；围栏内、块外、未闭合块与旧 `+++ log` 记录块保持逐行可见。

## 4. 不做

不做全文展开/折叠快捷键、搜索、批量操作；不改变持久化格式与块语法。
