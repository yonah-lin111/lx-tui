# 补充块折叠实施清单

状态：已实施（2026-10-22）。
设计：[design.md](design.md)。

## 实施项

- [x] `app/prompt/fold.rs`：从一次 `block_scan` 派生闭合补充块的隐藏区间与展开键；
      只折叠闭合块，未闭合/围栏/旧记录块保持可见。
- [x] `Prompt.expanded_supplements`：默认空；`set_text` 清空，撤销快照与
      `PromptHistory` 携带，正文写入经 `splice_text` 平移。
- [x] `visual_rows` 跳过隐藏行；光标归一到可见头部行尾；左右与按词移动整块跳过。
- [x] 折叠保留独立标题行 `{title: …}`，隐藏从标题行之后开始（无标题行时从起始行之后开始）。
- [x] 回车改道：折叠块可见头部（起始行行首除外）与隐藏区内的换行落在整块之后。
- [x] 写入保护：与隐藏区相交的插入/删除/替换整次拒绝并 Toast；选区复制只取可见行。
- [x] 起始行右上角新增折叠按钮 `[▸]`/`[▾]`；起始行以 `├─ … ┤` 绘制，标题行按块内普通行显示。
- [x] 斜杠新建补充块自动展开，光标落在标题内。
- [x] 拆分 `prompt/navigation.rs`，`prompt.rs` 保持 1000 行以内。

## 验证

- `cargo fmt --check`、`cargo clippy --all-targets -- -D warnings` 通过。
- `cargo test`：2927 项通过（新增 17 项折叠相关测试）。

## 终端验收建议

- 20 个补充块的加载视图每个只保留起始行与标题行。
- 点击右上角图标展开/收起；展开后编辑正文不受隐藏区保护影响。
- 折叠头部行尾回车在块后新增空行；起始行行首回车在块前新增空行。
- 跨折叠块框选删除被拒绝并提示；仅复制可见行。
