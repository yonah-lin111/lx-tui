## 1. 数据模型与迁移

- [x] 为引用文件夹定义独立记录类型和项目级快照，不复用提示词树 `PromptFolder`。
- [x] 按 `Workspace::prompt_key()` 归属列表；钉住 Prompt 时取被钉住工作区键；键变化时丢弃旧列表/弹窗/扫描结果。
- [x] 新增 SQLite 表 `workspace_referenced_folder`、每项目唯一约束、外键、稳定添加顺序；schema 5→6 迁移可重复打开，老 Prompt 数据不变。
- [x] DB 层实现 list/add/delete；删除按 id + 项目键双条件，避免跨项目误删；路径规范化后再入库。
- [x] 持久化服务加载/刷新所有同键工作区，写入失败不制造“已保存”假象；DB 不可用有可见反馈。
- [x] 精确测试：空库、旧 v5 库升级、二次启动、外键级联、重复路径、跨项目隔离、主 checkout/worktree 共享、写失败保留状态。

## 2. 路径输入与后台验证

- [x] `+ add folder…` 打开单行 TUI 路径输入（居中模态 72×8）；复用现有 `TextInput` 与模态容器，支持键盘编辑/粘贴/确认/取消。
- [x] 后台校验绝对路径、存在、目录类型、访问权限、UTF-8 与引用可表达性；canonicalize 后去重；错误文案区分失败原因。
- [x] 验证中阻止重复提交；项目切换或弹窗关闭后不应用迟到的验证结果。
- [x] 精确测试：合法内外目录、路径别名去重、文件/相对路径/失效路径、并发提交、迟到回执。

## 3. 工具栏与目录弹窗

- [x] 扩展工具栏按钮枚举与几何，把文件夹按钮置于 Pin 左侧；渲染、命中、tooltip、窄栏隐藏规则共用同一几何。
- [x] 目录弹窗为居中模态（72×18 固定尺寸，与内容搜索弹窗一致）；末行 `+ add folder…`；空态与 DB 不可用态各有明确提示。
- [x] 行样式与交互参照 Prompt 列表：`❯` 选中标记、`▸` 目录三角、名称（`…` 截断）与行右端 muted 绝对路径（中间截断）；单击只选中、双击打开、`↑`/`↓` 与滚轮移动、悬停移动高亮。
- [x] 行内不放复制/删除按钮：`Ctrl/Cmd+C` 复制 Markdown 目录引用、`Ctrl/Cmd+D`（或 `Del`）打开删除确认；底边提示快捷键。
- [x] 删除先确认，取消不变；确认只删 DB 记录，刷新同键视图；删除失败保留记录并提示。
- [x] 精确测试：按钮相邻关系、窄屏退化、固定几何与居中、行命中、单击/双击差异、动作行单击、弹窗内外点击、快捷键路由与效果。

## 4. 内容扫描与模糊匹配

- [x] 复用 `src/files.rs` 的 ignore walker；只在有必要时抽最小共享扫描配置，保持 `.gitignore`、噪声目录与符号链接行为一致。
- [x] 文件系统扫描在后台进行；根目录变化、关闭弹窗、项目键变化时以请求代号拒绝过期回执。
- [x] 记录相对路径、绝对路径和文件/目录类型；内存筛选大小写不敏感，先名称后路径，稳定排序；上限约 20,000 扫描条目、100 展示项，并显示截断。
- [x] 根目录失效/无权限、部分项读取失败、符号链接、深层目录、大树均有明确处理。
- [x] 精确测试：递归结果、忽略规则、模糊匹配顺序、深层目录、上限提示、扫描错误及过期结果丢弃。

## 5. 内容搜索弹窗与键鼠交互

- [x] 参照工作区分支选择构建内容弹窗（居中模态、固定 72×18）：顶行范围路径与右端原始路径复制按钮、`>` 前缀搜索框、双行候选、滚动条与状态提示齐备。
- [x] 候选两行：首行图标 + 名称（目录强调色、文件默认色，目录带 `/`），次行 `└─ ` + 父目录绝对路径（中间截断）；进入子目录后顶边右端显示当前文件夹名。
- [x] 点击行、`Enter` 或 `Ctrl/Cmd+C` 复制对应 `@[refer-file]`/`@[refer-folder]`；复制失败有反馈。
- [x] `Shift+Enter` 仅进入高亮目录并清空查询；`Ctrl/Cmd+Z` 返回上层（Cmd 组合同样可达）；`Esc` 回目录弹窗；底边提示与真实快捷键一致。
- [x] 输入焦点与 Prompt 编辑器隔离；弹窗期间底层点击不穿透、输入不会误改 Prompt 正文，`Ctrl+Q` 仍保持全局退出语义。
- [x] 精确测试：键鼠导航、目录与文件差异、复制三种文本、关闭与切换时状态清理、滚动与尺寸边界。
