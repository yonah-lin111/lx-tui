# Prompt 编辑页引用文件夹：设计

状态：**已实现并合并到 `dev`（2026-10-15）**。本文记录最终确认的边界与实现必须满足的交互、数据和失败语义；实现期间追加的两轮交互/外观修订已并入正文（§1.1、§4）。

## 1. 目标与范围

在 Prompt **编辑视图**工具栏的钉住按钮左侧增加文件夹按钮。点击打开引用文件夹**目录模态弹窗**（居中、固定 72×18，行样式与交互参照 Prompt 列表）：列出当前项目添加过的全部磁盘目录，行右端显示该目录的绝对路径，末行为 `+ add folder…` 动作项，底边提示快捷键；单击行只选中、双击（或 `Enter`）打开内容搜索弹窗，`Ctrl/Cmd+C` 复制引用，`Ctrl/Cmd+D` 或 `Del` 删除记录。可在该目录及子目录中模糊搜索文件和文件夹，复制 Markdown 引用，或用 `Shift+Enter` 进入高亮子目录。列表须写入本项目 SQLite，重新启动可恢复，同一 Git 仓库的主 checkout 与 linked worktree 共享。

项目里的“文件夹”有两种完全不同的实体：

| 实体 | 用途 | 数据来源 | 删除含义 |
| --- | --- | --- | --- |
| 提示词树文件夹 | 组织 Prompt 条目，最多两层 | 现有 `workspace_folder` | 原有级联行为，不受本功能影响 |
| 引用文件夹 | 指向磁盘目录，供复制引用与搜索 | 新数据库表 | 只移除目录引用，不删磁盘内容或正文 |

目录弹窗出现在编辑视图，且以**显示中 Prompt 所属工作区**为准；Prompt 被钉住时，切换侧栏活动工作区不改变弹窗归属。树视图、右栏折叠态和无有效项目键时不展示此按钮或禁用其打开行为。

### 1.1 已确认的产品决定

1. 目录路径是磁盘上的真实目录，允许项目内外的绝对路径；按项目共用，不是 Prompt 条目私有数据。
2. 末行 `+ add folder…` 打开 TUI 单行路径输入弹窗；提交前检查目录存在且可识别，并对重复目录拒绝新增。
3. 记录行复制 `@[refer-folder](绝对路径)`（`Ctrl/Cmd+C`）；搜索结果中的目录复制同格式，文件复制 `@[refer-file](绝对路径)`（`Enter` 或 `Ctrl/Cmd+C`）。搜索弹窗标题另提供原始目录路径复制。
4. 搜索递归覆盖文件和子目录，路径模糊匹配；跳过 `.git`、`node_modules` 等噪声目录及符号链接，后台扫描并限制结果展示。
5. 搜索弹窗的 `Shift+Enter` 沿用 Prompt `@` 面板语义：进入高亮目录，把搜索范围收窄到该目录；高亮文件时无动作。
6. 删除记录（`Ctrl/Cmd+D` 或 `Del`）先确认，只删除列表记录；磁盘目录及已有 Prompt 正文引用均保留。
7. 引用文件夹列表入 SQLite，重启、工作区切换后仍可用。
8. 引用文件夹三个浮层统一为居中模态且尺寸固定（仅受屏幕钳制）：目录弹窗 72×18、内容搜索弹窗 72×18、路径输入弹窗 72×8；高度不随记录数或候选数伸缩，避免交互中窗口跳动。
9. 目录弹窗的行显示与交互参照 Prompt 列表：`❯` 选中标记、`▸` 目录三角、名称与行右端 muted 绝对路径；单击只选中、双击打开，`↑`/`↓` 移动高亮、`Enter` 打开、`Esc` 关闭、鼠标悬停移动高亮；**滚轮只滚动列表视口，不移动高亮**（对齐 prompt 的 `@` 面板：视口到底/顶后钳制不循环，高亮可被滚出视口，键盘移动后窗口重新跟随高亮）。行内不再放复制/删除按钮。
10. 目录分色只用于文件与目录混排的场景（`@` 面板与内容搜索弹窗）：目录图标与名称用强调色，文件保持默认；纯目录的目录弹窗不额外着色。
11. 引用文件夹浮层整体不透明：浮层底色铺满整块区域（含文字单元格），浮层内滚动条轨道/thumb 叠加浮层底色；非浮层的滚动条保持透明以承接终端背景。

## 3. 数据模型与 SQLite

### 3.1 归属和规范化

数据库以现有 `Workspace::prompt_key()` 归属目录列表。Git 主 checkout 与 linked worktree 的 `repo_root` 相同，因此共享一组目录；非 Git 工作区取创建时固定 `cwd`。不以活动标签、编辑的 Prompt id、临时提示词 id 或可变的终端 cwd 作为键。加载和写入均对当前显示中 Prompt 的所属工作区取键；仓库元数据晚到导致键变化时，按现有 `loaded_key` 规则重新载入，作废旧键下的弹窗与扫描结果。

添加时把输入去首尾空白；要求绝对路径、现存目录。通过后台任务做 `canonicalize`，将规范绝对路径作为稳定身份与复制值；相对路径、普通文件、不可访问目录、非法 UTF-8 路径给明确错误，不写库。规范化后比较重复项，包括不同写法指向同一物理目录的情况。目录以后被移动或删除时记录仍保留，弹窗显示不可用状态；搜索时报“目录不可访问”，允许用户删除记录。**不自动清理**，避免临时卸载导致用户数据消失。

路径复制必须调用现有 `format_reference` 一类的无损格式化能力；如果路径无法以引用语法表达，则添加时拒绝并说明原因，不能生成无法解析的 `@[refer-*]` 文本。目录和文件搜索结果均以绝对路径构造引用，且只从已扫描的目录内部结果生成。

### 3.2 表和迁移

新增独立表，建议名 `workspace_referenced_folder`，字段：`id INTEGER PRIMARY KEY`、`workspace_id TEXT NOT NULL`、`path TEXT NOT NULL`、`created_at TEXT NOT NULL`；`FOREIGN KEY(workspace_id) REFERENCES workspace(external_id) ON DELETE CASCADE`；`UNIQUE(workspace_id, path)`。按 `id ASC` 列出，使添加顺序稳定；不为当前需求增加独立排序字段、enabled 状态或嵌套结构。已有 `workspace_folder` 和 `workspace_prompt` 不改结构、不重建。

schema 从 5 升到 6；空库直接具备新表，已有 v1–v5 库在现有迁移链完成后以单事务创建新表并推进 `user_version`。迁移失败不推进版本，下次启动可重试；旧 Prompt、页和提示词树记录保持原样。数据库层提供按项目键 list/add/delete 的最小接口，add 依靠唯一约束实现幂等去重，delete 以记录 id 与项目键联合约束，避免错误归属删除。

应用状态保存当前项目的引用目录快照，和 `loaded_key` 同步；`Effect` 只传路径/id/项目身份，执行失败不假装已保存。建议写成功后从 DB 重载同键的所有工作区快照；失败保留输入弹窗与错误反馈，用户可重试。若数据库不可用，弹窗应明确展示“无法加载/保存”，不可把临时内存数据伪装成已持久化。

## 4. 浮层与弹窗

### 4.1 工具栏及目录弹窗

按钮位于 Pin 的左侧，视觉宽度和按钮间距沿用工具栏；窄栏容纳不下时按现有完整按钮隐藏规则退化，不能裁半个图标或覆盖其他按钮。点击打开**居中模态**（宽 72、高固定 18，与内容搜索弹窗同尺寸同底色）；`Esc`、再次点击按钮或点击弹窗之外关闭，弹窗内部空白点击保持打开，打开期间底层点击不穿透。标题为 `Folders`，底边显示快捷键提示；空列表展示一条不可选的 muted 空状态提示（数据库不可用时同位置给出不可用提示）。

每一行按 prompt 列表式渲染：选中行行首 `❯ `，其后 `▸ ` 目录三角与目录末段名（放不下以 `…` 截断），行右端以 muted 显示该目录**绝对路径**（中间截断，最多占半行宽；剩余宽度不足时整段省略，名称独占）。整行铺浮层底色，悬停/键盘当前行铺浮层选中底色；名称不额外着色（弹窗内全部是目录，无需与文件区分）。末行为强调色动作项 `+ add folder…`。

交互：`↑`/`↓` 移动高亮；滚轮只滚动列表视口（高亮不动、越界钳制不循环，与 prompt 的 `@` 面板一致；键盘移动高亮后窗口重新跟随）；**单击记录行只选中、双击打开内容弹窗**；动作项单击即打开路径输入；`Enter` 打开高亮行；`Ctrl/Cmd+C` 复制高亮目录的 Markdown 引用；`Ctrl/Cmd+D`（或 `Del`）打开删除确认；`Esc` 关闭。行内不放复制/删除按钮，快捷键在底边提示。列表总数不因视口限制被截断（超出时右缘一列显示滚动条，与 Prompt 列表同款：轨道 muted、thumb 亮色，轨道点击跳转、拖拽 thumb 实时滚动）。弹窗行进入搜索时保留原始所属项目键和目录 id，防止切换工作区后把旧结果归给新项目。

`+ add folder…` 打开单行路径输入弹窗（居中模态，宽 72、高 8，容纳长绝对路径），默认空输入；支持粘贴、方向键、Home/End、Backspace/Delete、`Enter` 提交、`Esc` 取消。提交先进入验证中状态，后台检查路径，再写库。失败仍留在输入弹窗并给具体原因（空值、非绝对路径、不存在、非目录、重复、不可访问、数据库失败）。成功关闭输入弹窗、刷新列表、将新项滚动到可见范围（重开目录弹窗时高亮该新项）。重复提交在验证中禁用，避免并发插入。

删除动作（`Ctrl/Cmd+D` 或 `Del`）弹确认浮层，文案显示待删目录；确认时用稳定 id 删除数据库记录，再刷新同键工作区。取消则保留原状态。删除失败显示错误，记录仍在；删除不会调用 `remove_dir`、不会读取/改写 Prompt 正文。被删项的内容搜索弹窗若仍在，必须关闭或标记失效并丢弃在途扫描结果。

### 4.2 目录内容搜索弹窗

视觉沿用工作区分支选择弹窗的模态容器：居中、固定 72×18（不随候选数量伸缩），带标题、单行搜索框、可见滚动区域和状态提示。顶行展示当前搜索范围的绝对路径（中间截断），右端 `[❐]` 复制该**原始绝对路径**（不复制 Markdown 引用），“结果已截断”提示紧贴该按钮左侧常显；进入子目录后顶边右端显示当前文件夹名。候选每项两行：首行 `▸`/`•` 图标 + 名称（目录带 `/`，目录用强调色、文件默认色），次行 `└─ ` + 父目录绝对路径（中间截断），同名结果据此区分。搜索框沿用模态单行输入样式（`>` 前缀 + 视口 + 占位）。点击行、`Enter` 或 `Ctrl/Cmd+C` 复制高亮项引用，复制成功后给短暂反馈；复制失败保持弹窗并显示失败，不声称成功。搜索框文本选中时，原生复制键的文本复制语义优先；没有选区时可沿用参考面板的高亮项复制快捷键，但不覆盖现有全局 `Ctrl+Q`。

打开弹窗以选中目录为根，空查询显示根下候选；输入时按相对路径及文件名做大小写不敏感模糊匹配，先匹配文件名再匹配路径其余部分，稳定排序，同分以路径排序。搜索结果包含目录和文件，但不包含根目录本身。`Shift+Enter` 对高亮目录进入该目录并清空或保留查询的取舍：**清空查询**，使子目录内容立即可见；对文件无动作。`Ctrl/Cmd+Z` 回到父搜索范围（终端支持 kitty 协议时 Cmd 组合同样可达），回到初始根后保持弹窗；`Esc` 关闭弹窗并回目录弹窗。目录进入和返回只变更弹窗范围，不修改 Prompt 正文，也不写数据库。弹窗底边提示这些快捷键。

扫描与筛选分开：打开或进入目录时后台扫描该范围，完成后在内存中按输入即时筛选；对明显过大的树设扫描上限（建议最多 20,000 个文件系统条目）、展示上限（建议 100 条）并显示“结果已截断”。限制扫描数、耗时与结果数是性能保护，不应把超过上限误报为“无匹配”；需要更精确结果时用户可进入子目录缩小范围。`.gitignore`、常见噪声目录和符号链接的规则尽量与 `src/files.rs` 一致；隐藏文件是否出现沿用现有 `@` 扫描器的规则。扫描根本身丢失或权限不足时显示错误和重试入口。

每次打开、换目录、项目键改变或关闭都递增请求代号；后台结果携带根路径、项目键和代号，只有与当前弹窗完全一致才写入状态。旧扫描可取消则取消，不能取消时返回后丢弃，避免慢结果覆盖新查询。扫描不得在 ratatui 渲染、`app` 更新或事件循环同步路径执行。渲染只读取已就绪的状态快照。

## 5. 事件、依赖方向与失败语义

数据流：工具栏命中（`layout`）→ 输入/鼠标路由（`input`/`event`）→ `app::update` 改纯状态或产生 effect → `db::service`/后台文件扫描/剪贴板 → 事件回执 → `app::update` 验证身份并更新快照 → `ui` 只读渲染。数据库 CRUD 只在 `db/`，文件遍历复用 `files/` 能力并由事件层后台调用，剪贴板走现有 effect 与 `platform/`。OS 专属行为不进入核心模块。`ui/widgets` 保持无业务语义，仅收几何/标签；领域浮层渲染留在 `ui/overlay/`。

关键失败与恢复：

| 场景 | 预期 |
| --- | --- |
| 无项目路径键 | 不打开引用目录弹窗；不创建无法归属的记录。 |
| 保存前目录被删除或无权限 | 输入弹窗保留，显示验证错误；DB 无新记录。 |
| 数据库写失败 | 不显示为已持久化；保留重试入口，记录 `tracing` 警告。 |
| 数据库重复键 | 视为已存在，提示重复，不生成第二项。 |
| 已存目录后来失效 | 列表仍显示，可删除；进入搜索显示错误。 |
| 扫描局部 IO 错误 | 跳过坏项，若根本身不可用则报错；绝不 panic。 |
| 工作区/项目切换、删除项目记录、关闭弹窗 | 在途结果不写入新的弹窗。 |
| 剪贴板失败 | 保持弹窗并显示失败；不出现 copied 成功状态。 |
| 超过扫描/展示上限 | 显示截断信息，仍可进入更小目录继续找。 |
| 窄终端/窗口缩放 | 按屏幕钳制、完整按钮优先；浮层键盘仍可关闭。 |

## 6. 验收标准

1. Git 主 checkout 和 linked worktree 打开同一项目时共享目录列表；其他项目互不串用。Prompt 被钉住时操作始终作用于被钉住的项目。重启应用后列表和顺序仍在。
2. 添加项目内、项目外合法目录成功；相对路径、文件路径、重复路径、已删除目录被拒绝且提示明确；规范化后的重复路径只留一项。
