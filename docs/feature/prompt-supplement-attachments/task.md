## 3. 解析与附件索引

依赖：文档审核通过。

- [ ] 基于现有解析生成父任务对应的补充块列表，保留原文顺序。
- [ ] 明确逻辑行范围到 UTF-8 字节区间的转换，避免包含邻接普通正文。
- [ ] 标题使用已有解析，空标题有显示兜底，重复标题不混淆身份。
- [ ] 为不安全、未闭合、围栏和块外标记定义确定的原文降级路径。
- [ ] 复用扫描结果，避免每个附件再次扫描全文造成 O(N×全文长度) 工作。

验收：20、100 个附件均归属正确；相邻任务不串；仅浏览不修改正文。

- [ ] 区分真实文本视觉行与合成的附件入口行。
- [ ] 每个有附件的任务只生成一个固定高度入口，无附件不占行。
- [ ] 绘制、命中、光标、滚动和行数统计统一使用显示映射。
- [ ] 按最终契约处理光标跨隐藏区、Backspace/Delete、Home/End 与鼠标拖选。

- [ ] 不保留被隐藏的补充块旧按钮命中区。
- [ ] 对折行、中文宽字符、滚动后和窗口缩放后的几何做针对性验证。
- [ ] 按选区复制契约区分无选区与仅选中合成行，避免空文字选区误触全文复制回退。

验收：点击第 N 个可见文本行定位到对应原文；附件入口不被当作可编辑字符；后续正文不会误删隐藏附件。

- [ ] 编辑会话固定文档、页、父任务、子块与打开修订。
- [ ] 依约处理保存、取消、切换附件和退出，不默默丢弃修改。
- [ ] 保存前验证身份、修订与原文范围；失配时拒绝覆盖并保留草稿。
- [ ] 实际变化经局部编辑路径形成正确 undo/redo；无变化不造空历史。
- [ ] 特别处理空正文插入与结构保护拒绝；不得用 `set_text` 清空历史后伪装提交成功。
- [ ] 回到任务时恢复合理的滚动与焦点，光标不能落在隐藏子块内部。
- [ ] 依最终方案接入复制、清理、删除、新增；保留现有撤销和复制语义。

| 维度 | 必测场景 | 可观察断言 |

## 9. 可执行工作包与依赖

以下任务全部依赖第 1 节的用户整体审核。允许一个大工作包交给一个子任务执行；有独立模块时最多两个并行子任务，共享入口文件由一个执行者维护。不能同时修改同一状态定义和同一渲染入口造成互相覆盖。

## 10. 精确测试计划与验证记录

对原有缺陷先写会失败的复现：隐藏区光标越界、跨区误删、空选区复制全文回退、保存后输入合并撤销。其余测试验证可观察行为与数据不变量，不逐个镜像私有实现函数。

| 测试归属 | 拟测试行为 | 最小失败断言 |
| --- | --- | --- |
| `app::prompt` 或新 presentation 子模块 | 多父任务、0/1/20/100 子块、局部空行收敛 | 原文不变；入口数等于有安全子块的父任务数；后续正文可定位 |
| `app::prompt` 领域提交 | 空正文、新建取消、同内容保存、元数据、Other 历史 | 无变更无 dirty/历史；已改提交与后续输入分步撤销 |
| `app::prompt::viewport` | 原文/集中往返、中文、折行、隐藏区 cursor、方向键 | 无反向切片；光标/入口焦点合法且可见 |
| `app::update::selection` | 多片段复制、只选入口、跨附件替换/剪切 | 复制不含隐藏文本；拒绝写入不改正文/剪贴板/历史 |
| 新 `app::supplements` / update 模块 | dirty 返回三选一、删除默认取消、目标失效 | 不丢草稿，不串目标，确认删除只改目标范围 |
| `input::tests` | 主 Prompt F4、模态 Save、候选 Esc、Enter 换行 | 不误触底层保存/退出，不把模态键发送 PTY |
| `ui::prompt`、`ui::overlay`、layout | 入口/按钮命中、列表滚动、窄/极矮尺寸 | 绘制与命中矩形一致；零尺寸不访问越界；当前项可达 |
| 现有块操作集成测试 | 父任务复制、子块复制、状态/清理/删除 | 原有语义保持；原文模式仍可直接操作 |

- **T1 索引与领域提交**：`app/prompt/presentation.rs` 一次 `block_scan` 派生安全父子索引（父子均闭合、子严格在父内），围栏/块外/旧 `+++ log` 保持原样；`app/supplements.rs` 冻结标题行与正文区间快照；`Prompt::commit_supplement` 走 `Other` 分组 + `replace_span`，保留起止行、命令名、`{id:}` / `{wt:}`。
- **T2 显示投影**：集中视图隐藏安全子块并收敛直接相邻的块内空行，每个父任务只在结束边框前生成一个 `Supplements · N [open]` 入口；绘制、命中、滚动、光标与选区共用同一份 `display_rows`。所有写入入口经 `protected_edit` 拒绝与隐藏区相交的编辑（含零长度插入），拒绝时给出可见提示。
- **T3 原文切换与可见复制**：`F4` 与工具栏 `[src]` / `[view]` 切换集中/原文；不置脏、不清历史，展示方式随 `PromptHistory` 往返但不进文本快照。选区复制只取可见原文（软换行直接连接、跨逻辑行保留换行、合成入口不产出文字）；「有选区但无文字」不再回落全文。
- **T4/T5 附件会话与模态**：`Overlay::Supplements` 单模态承载列表/详情/未保存确认/删除确认；96×28 期望尺寸、32×10 最小编辑尺寸（不足时只提示放大、暂停写操作、保留草稿）；列表含末尾 `+ add supplement` 动作行，键盘可达；未保存确认默认焦点 `keep editing`、删除确认默认焦点 `cancel`；`Ctrl/Cmd+S` 保存、`Ctrl/Cmd+Z`/`Y` 本地撤销重做、`F6`/`Shift+F6` 切换标题/正文焦点、`Esc` 先关候选再退出；`/supplement` 与自定义 `block: supple` 走同一草稿流程（取消保留命令行，保存时整行替换为一次 `Other` 提交）。

与已审设计的已知偏差（后续可补）：

1. 详情正文草稿是「正文-only」编辑器加独立标题行，未做 §12 描述的「只读父壳 + scratch」。因此草稿正文内不提供补充块命令上下文；标题与正文的保存边界由域层重建保证。
2. 列表未绘制滚动条（轨道/拖拽），仅支持键盘与滚轮窗口滚动；入口行未接 tooltip。
3. `Ctrl+C` 仅用于列表复制当前附件正文，详情正文内不复制。

## 11. 审核通过后的首个执行动作

先复查索引与受影响文件当前状态，确认没有与本设计重叠的未识别用户改动，记录生产文件行数，然后实现 T1。普通文件变更已由实施授权覆盖，但 Git 暂存、提交、分支与合并仍无授权，不执行。

最终交付需列明实际修改、精确验证、未完成的人工终端验收，以及任何与已审文档不一致的决定。若需要改变 D1–D9 的产品边界，先说明具体差异并重新确认；常规可逆实现细节在已审设计内自行处理。
