## 1. 块协议与上下文

- [ ] 在 `src/app/markdown/` 增加 `+++`、`$$$` 起止解析、块类型及行范围；两端命令名严格匹配。
- [ ] 统一计算普通正文、`&&&`、`+++`、`$$$`、围栏和结构行上下文；`+++` 不得越过父 `&&&` 结束行。
- [ ] 兼容参考格式同行标题、可选元数据和旧 var 标记；旧 `+++ log`/`%%%` 保留记录块语义。
- [ ] 精确测试未闭合、错名结束、相邻块、交叉标记、中文标题、代码围栏与块外 `+++`。

## 2. 内置命令与范围

- [ ] 增加 `/supplement`、`/var`、`/singleLine`、`/multiLine` 的命令标识、保留名和候选描述。
- [ ] `/supplement` 只在 `&&&` 正文出现；`/var` 只在普通正文出现；单行/多行命令只在 var 正文出现。
- [ ] 实现规范块文本、整行替换、标题/键名的初始光标与选区、单步撤销；Esc 和鼠标确认沿用现有面板行为。
- [ ] 测试各上下文的命令过滤、插入结果、光标位置、撤销与重新打开面板。

## 3. Settings 自定义补充块

- [ ] `agentBlock` 记录增加 `block_type: template|supple`；旧文件缺省为 template，未知值明确报错。
- [ ] `block: supple` 生成 `+++ <name>` 外壳，使用设置正文及标题；User/Project 目录与同名覆盖规则不变。
- [ ] Settings HTTP 列表、PUT/删除和页面表单支持块类型选择与自定义内容，保存失败保留草稿。
- [ ] 设置保存成功后沿用现有通知与事件层重载，正在编辑的 Prompt 原文不回写。
- [ ] 覆盖文件 round trip、兼容值、非法值、保留名、作用域覆盖、HTTP CRUD 和候选刷新测试。

## 4. 变量解析与全文引用

- [ ] 从当前 Prompt 的已闭合 var 块提取变量；支持单行、层级/点号、三引号及 `|`/`>` 多行值。
- [ ] 过滤 `@content:`、默认占位和空值；后定义同名键覆盖先定义，候选只显示唯一名称。
- [ ] 旧式首部 frontmatter 仅在不存在有效 var 块时作为兼容来源；不混合两种来源。
- [ ] 在现有字母候选面板展示变量并标明来源；普通正文和 `&&&` 正文可选，其他位置不触发。
- [ ] 确认候选后用变量值替换查询区间，保留多行内容，单步撤销；不建立动态绑定。
- [ ] 测试多个 var 块、同名覆盖、坏条目、空值、编辑/删除/撤销后的刷新、跨 Prompt 隔离和纯值插入。

## 5. 块操作与编辑细节

- [ ] `+++` 清理未填写列表项、删除整块；父 `&&&` 复制仍排除完整补充子块。
- [ ] var 清理、删除、合并到首块、移到文首连续 var 块组后；处理已是首块或已在顶部的无操作结果。
- [ ] var 块折叠/展开只改变视图状态；编辑、滚动、缩放和切换 Prompt 不留下错误锚点。
- [ ] var 键值行的全角冒号转半角与 Tab 导航；三引号正文不转换。
- [ ] 测试每项操作的光标/选区、空行、重复执行、撤销重做以及折叠不改正文。
