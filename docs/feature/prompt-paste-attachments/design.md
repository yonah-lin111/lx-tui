# Prompt 粘贴路径与引用快捷输入设计

状态：已实施（见 §14 修订历史）；文中冲突处以 §14.3 为准。

## 1. 目标与边界

在 prompt 编辑视图中粘贴**路径文本**时，先把纯路径文本写入正文作为占位，再打开紧邻编辑器的二级面板改写格式（对齐 lx-agent 的 `LxMarkdownEditor` / `useAgentInputPaste`）：

1. **插入引用**：把占位文本改写成 `@[refer-file](path)`、`@[refer-folder](path)` 或 `@[refer-image](path)`。
2. **插入路径**：保持占位文本（可直接使用的本机路径）。

取消（Esc/外部点击）回滚到粘贴前文本与光标，不留多余撤销步。

图片与文件**都只以路径表达**：应用不读取系统剪贴板，也不把任何内容落盘或登记为资产（见 §4.2 与 §14.3）。截图工具复制的位图没有路径，不属于本功能范围；需要引用图片时先让文件落到磁盘，再粘贴其路径。

文件类型自动识别：目录为 folder，已识别的图片文件为 image，其余普通文件为 file。多项粘贴只显示一组操作选项，对全部项使用同一种处理方式。不能静默跳过目录。本任务不保存附件列表。

新增字母快捷输入：在可编辑正文输入至少 2 个字母/路径字符时，从有效范围内已出现的 `@ref/` 短引用、`@` 提及和 `@[refer-*]` 引用生成候选。`ac` 可用子序列匹配 `@abc`；确认后插入 **`@ref/末两段`（文件夹带尾 `/`）** 短格式替换 `ac`，不写回候选完整原文。候选右端显示来源类型 tag，如 `[file]`、`[folder]`、`[refer-image]`、`[ref-file]`。快捷面板不扫描文件系统，也不产生新引用目标。

本任务不增加 agent 发送流程，不修改 PTY 粘贴语义，不把普通文本的斜杠命令当成文件路径。

## 2. 已确认决策

| 决策 | 规则 |
| --- | --- |
| 正文表达 | 路径与引用全部写入正文；不引入附件列表，路径粘贴不复制外部文件 |
| 持久化 | 只保存正文；数据库无资产/附件表 |
| 图片 | 只接受路径表达式；不读取剪贴板位图、不落盘、不登记、不回收 |
| 外部文件 | 只被引用，永不被删除或复制 |
| 路径识别 | 仅实际存在的本机绝对路径与 `file://` URI；支持多行；其余文本照常粘贴 |
| 处理选择 | 引用 / 路径；类型自动识别，无二次手选 |
| 快捷候选范围 | 模板块内只读该块已有引用；普通文本区读当前 prompt 全文 |
| 快捷确认 | 候选原文完整替换触发片段，右侧显示类型 tag |
| 平台 | macOS、Windows、Linux；无平台读取能力依赖，路径解析为纯函数 |

## 3. 现状与参考实现

- `src/event/mod.rs` 的 `TerminalEvent::Paste(String)` 在 prompt 聚焦时进入粘贴入口：全部路径有效时占位插入 + 提案，否则按普通文本插入。
- `src/platform/mod.rs` 实现异步文字**写**剪贴板与粘贴路径解析（绝对路径/`file://`）；不读取系统剪贴板。OS 分支继续收口于 `platform/`。
- `src/app/prompt.rs` 持有文本、撤销、面板、已保存状态与修订号；`mention.rs` 管现有 `@` 文件扫描。面板优先级为文件提及 > 斜杠 > 块命令，粘贴面板额外压过全部。
- `src/ui/prompt.rs` 有共用命令面板渲染，`src/layout.rs` 有编辑器几何与鼠标命中；新增入口复用这两处机制。
- `src/app/update/prompt.rs` 将编辑器内容同步到临时草稿或已保存条目；`src/db/mod.rs` 的 `workspace_prompt` 只有正文；持久层由 `db/service.rs` 执行效应。
- 参考仓库 `lx-agent` 的 `useAgentInputPaste` 在粘贴后给出 reference/path；`createMarkdownReference(type,path)` 产出 `@[refer-${type}](${path})`。`markdownTemplateFileCommands` 的快捷输入最短 2 字符，按名称/路径前缀、包含、子序列排序。

因此 TUI 把“终端送来的文本”作为唯一粘贴入口，归一成一种纯数据粘贴提案：图片与文件没有额外通道。

## 4. 数据模型和不变量

### 4.1 正文表达

本功能不引入附件列表：文件与文件夹、图片都以引用标记或纯路径写在正文里。因此 `Prompt`、`TempPrompt`、`PromptItem` 与数据库都只保留正文，撤销快照也只有文本与光标。

### 4.2 不落盘、不登记、不回收

应用不创建、不管理任何资产文件：没有管理目录、没有资产表、没有垃圾回收与孤儿扫描。正文引用指向的始终是用户自己的外部文件；本功能不删除、不复制、不移动它们，也不再需要“引用计数”式的存活判断。

### 4.3 粘贴提案

纯数据 `PasteCandidate` 含路径、`File|Folder|Image` 与 `reference_ok`（引用语法能否无损表达该路径）；提案含候选列表与登记锚点（选区优先、否则光标）与请求代号。结果只在目标编辑器未变、编辑修订未变时接受；否则丢弃，不插入旧结果、不改正文。

处理选项与候选类型分开建模，不让 UI 文案决定行为。占位插入先替换原选区并写入纯路径文本（左邻非空白补空格、末尾补空格），随后“引用”改写占位文本、“路径”保持占位文本；“取消”回滚到粘贴前的文本、光标、保存态与修订号，占位插入与格式改写同属**一步撤销**。触碰模板块受保护行（标题行、`{wt:}` 绑定行）时不写入也不打开面板。确认后关闭粘贴面板并保持 prompt 焦点。

## 5. 输入和面板交互

### 5.1 粘贴入口

只处理终端括号粘贴 `TerminalEvent::Paste(text)`：整段是**存在**的本机路径集合时，先按锚点写入纯路径占位并打开面板；其余文本（含空内容）同步走既有 `InsertText`（空内容不修改正文）。不设工具栏按钮，不设快捷键，应用不读取系统剪贴板。

路径文本须先整体解析：支持单行和逐行 `file://` URI/绝对路径，逐项 URI 解码；任何一项不是存在的本机路径时，整段按普通文本处理，不做部分转换。终端拖拽/部分复制会带 shell 转义反斜杠（`ai_agent_api\(1\).md`），因此每项先按原文判定，原文不存在时再去掉反斜杠判定一次（命中后占位与候选用去转义后的真实路径，引用按语法重新转义）。

普通文本插入后压制补全面板直到下一次编辑/移动：粘贴不是“正在输入”，否则粘贴文本尾部凑巧像触发词时，紧跟的 `Enter` 会把这段正文替换成候选原文（把刚粘贴的路径吃掉）。不得仅因首字符为 `/` 或含图片扩展名就弹出面板。保持路径中的空格和非 ASCII 字符；引用标记中的 `)` 等分隔符按本项目 Markdown 引用语法处理，不能生成截断或歧义文本。若当前语法无法无损表达某路径，则禁用引用选项、保留路径选项。

### 5.2 二级选择面板

面板锚定当前 prompt 光标行，屏幕边界不足时向上展开；沿用现有命令面板的键盘和鼠标命中模式。`Up/Down` 改变高亮，`Enter` 确认，`Esc` 取消；外部点击关闭且不穿透编辑区。面板展示操作名与当前候选数。选择期间捕获或取消其他互斥面板；优先级为粘贴选择 > 现有 `@` 提及 > 字母快捷 > 斜杠 > 块命令。面板关闭后才重算被压制的其他面板。

占位文本就是候选的源路径，引用改写也使用同一路径。

正文中的 `@[refer-*](path) ` 与 `@文件 ` 提及同构：光标紧跟尾随空白时一次 Backspace 删除整段标记（含尾随空白），单步可撤销；无尾随空白或标记非法时退化为逐字符删除。

### 5.3 字母快捷输入

触发词只取光标前、单词边界后的 2 个及以上常见路径字符，前缀为 `@`、位于已有 `@[refer-*]` 标记内部、代码围栏、结构元数据行或模板保护区时不触发。触发源仅为当前 prompt **正文已出现**的 `@ref/` 短引用、`@` 提及、`@[refer-file/folder/image]` 引用。

候选作用域以模板块起止行为分段边界：光标在块内时只收集所在分段（块内提及/引用不跨块、不泄漏到块外，未闭合的外层块也不会把后面的新块并入自己的正文）；光标在块外时收集全部块外分段（块内内容同样不可见）。重复的完整标记只展示一次，保留首次出现顺序作同分排序。输入 `ac` 能以不连续子序列匹配 `abc`；优先级为名称完全匹配、名称前缀、路径前缀、名称包含、名称子序列、路径包含。无候选不显示。确认后按 `@ref/末两段` 短格式替换触发词（作为一次撤销步），短名生成失败时才回退候选完整原文；Esc 只关闭本轮面板，继续编辑后再重算。

**`@ref/` 短引用格式**（本批次新增）：`@ref/` + 路径末两段（`a/b`），文件夹补尾 `/`；不以 `/` 开头，因此不会被读成根目录。类型由形状推断（尾 `/` 文件夹、图片扩展名图片、其余文件），不再写 `refer-*`。短名只是「同一片段内已出现过的路径」的简称，完整长路径仍以文档中已有的 `@[refer-*](…)` / `@` 提及为准。高亮独立一色（`style::markdown_short_ref`：Indexed 141 柔紫 + 加粗、无下划线），与 `@` 提及黄、`refer-file` 绿、`refer-folder` 橙、`refer-image` 品红都不重样；整段一个 token，路径里的 `*` / `_` 不参与强调解析，句末 `.` 视为句子标点不计入标记。`@ref/…` 与 `@` 提及、`@[refer-*]` 同构：光标紧跟尾随空白时一次 Backspace 删净整段（含空白）、单步可撤销；本身也是面板候选来源（tag `[ref-file]` / `[ref-folder]` / `[ref-image]`）。实现见 `app/markdown/short_ref.rs`（纯函数：`short_ref_name` / `short_ref_marker` / `short_ref_kind` / `short_ref_ranges` / `short_ref_deletion_range`）。

右侧 tag 依据引用的实际语法/候选类型生成：`@` 文件候选 `[file]`，可确定目录时 `[folder]`；`@[refer-file]`、`@[refer-folder]`、`@[refer-image]` 分别显示 `[refer-file]`、`[refer-folder]`、`[refer-image]`；`@ref/` 短引用按形状显示 `[ref-file]`、`[ref-folder]`、`[ref-image]`。tag 使用固定右侧空间，长路径从中间或末尾截断，不能挤出面板或改变命中行宽。窄屏仍应可选，tag 放不下时优先保留引用名称与高亮。

## 6. 模块归属

| 模块 | 责任 |
| --- | --- |
| `platform/` | 剪贴板写入、粘贴路径解析与图片签名探测；纯函数，不持有 AppState |
| `event/` | 终端粘贴入口、候选校验与提案建立；不阻塞事件循环 |
| `app/prompt/` | 粘贴占位插入、面板改写/回滚与快捷候选的纯状态转换；撤销、修订、面板互斥 |
| `app/markdown/` | 现有引用/模板块语法的复用或最小扩展；引用解析、格式化与整段删除为纯函数 |
| `app/update/` | 当前 prompt、临时草稿和已保存条目的正文同步及效应出箱 |
| `db/` | 建表/迁移与正文读写；无资产表 |
| `ui/`, `layout.rs` | 只读绘制、编辑器几何、二级面板与鼠标命中；可见文案放 `ui/text.rs` |

不为此任务改动 `tui/` 的终端恢复顺序；OS 分支不得进入 `event/` 或 `app/`。

## 7. 失败语义与验收

- 已保存 prompt 和临时草稿在切换工作区/编辑目标后，正文（含引用）随原 prompt；重启后正文正确恢复。
- 路径候选只做存在性校验，不改动任何文件；不存在或非法路径回退普通文本插入。
- 旧数据库无损升级，旧 prompt 正文不变；迁移和保存失败保留可恢复状态并向用户反馈。
- 已有 `@` 扫描、斜杠和块命令的键盘/鼠标行为不回退；新面板在窄屏和工作区切换时不漂移。
- TUI 外观需要用户运行 `cargo run` 检查；自动化验证覆盖纯状态、数据库迁移/级联、平台路径解析和事件路由。

## 8. 精确状态流

### 8.1 现有状态通路与字段归属

当前屏幕中的编辑器是 `AppState.prompt: Prompt`；切换工作区时，`src/app/update.rs::load_displayed_draft` 从工作区的 `PromptDraft { editor, root }` 取出完整编辑器。当前条目内容通过 `commit_prompt_buffer` 写回 `TempPrompt.content` 或 `PromptItem.content`，再产生 `SavePromptContent` 效应。`SaveDraft` 效应先创建数据库记录，成功后 `finish_draft_save` 才移除临时项并绑定新条目。正文（含引用）必须遵循同样通路，不能只存在屏幕中的 `Prompt`。

| 位置 | 持有内容 | 失效时机 |
| --- | --- | --- |
| `Prompt` | 当前正在编辑的正文、字母面板与粘贴面板的纯状态、修订号 | 切换编辑目标时提交并重建；切换工作区时随整个 `PromptDraft.editor` 停泊 |
| `TempPrompt` | 临时草稿正文 | 用户删除临时项，或 `SaveDraft` **成功**后移除 |
| `PromptItem` | 已保存条目的正文缓存 | 树重载时从数据库重建 |
| `PasteState` | 在途请求与面板候选 | 确认/取消/失效或新请求覆盖；占位文本本身进撤销快照，不进数据库 |
| 数据库 | 已保存条目的正文 | 删除记录即删除正文 |

`Prompt::set_text` 重置文本、编辑历史与面板状态；加载条目正文即加载全部内容。`commit_prompt_buffer` 只比较正文。临时项进入/离开编辑器时，`TempPrompt` 与 `Prompt` 间复制正文。

### 8.2 从输入到确认的顺序

```text
终端 Paste(text)
  -> 整段路径解析：全部为存在的本机路径才建立候选
  -> 校验目标编辑器与编辑修订未变
  -> 按锚点占位插入纯路径文本（一次撤销步）并打开面板
  -> 用户选引用（改写占位）/ 路径（保持占位），或取消（回滚占位）
  -> 一次状态转换 + 一步撤销 + 更新修订号
  -> 临时项写回内存 / 已保存项排队同一保存效应
```

终端粘贴是同步编辑行为，不起后台任务、不产生临时文件。结果处理不得凭 `PaneId` 单独认定目标，因为同一个编辑器对象可能已绑定另一条目。

### 8.3 面板状态机

| 当前状态 | 事件 | 下个状态 | 文本副作用 |
| --- | --- | --- | --- |
| Idle | 全部有效的路径候选 | Choosing | 占位插入纯路径文本（一步撤销） |
| Idle | 非路径文本/空内容 | Idle | 普通文本插入或不修改正文 |
| Choosing | 上/下或悬停 | Choosing | 只改高亮 |
| Choosing | Enter/点击可用项 | Idle | 引用改写占位文本 / 路径保持占位文本 |
| Choosing | Esc/外部点击/失焦/目标变化 | Idle | 回滚占位插入（含撤销步），正文回到粘贴前 |
| Choosing | 新粘贴 | Choosing | 先取消旧提案，再处理新输入 |

禁用项不能成为键盘高亮或点击确认目标；两项都不可用时直接关闭（占位文本按路径保留）。`Ctrl+Q` 始终维持应用级退出优先级。面板打开时可用的编辑命令仅导航、确认、取消；其他按键按现有面板策略吞掉，不写入 PTY。关闭后重新调用既有面板收敛函数，保证 `@`、斜杠和块命令不会同时绘制。

## 9. 存储格式与迁移

数据库 `SCHEMA_VERSION = 3`（版本号保留自开发期的资产/附件结构，避免已有库被判为过新）。`workspace`、`workspace_folder`、`workspace_prompt` 使用自增 `id INTEGER` 作内部行标识、`external_id TEXT NOT NULL UNIQUE` 作稳定跨表标识；`workspace_prompt.folder_id` 与 `workspace_id` 都是指向其他表 `external_id` 的 `TEXT` 外键。Schema 只包含这三张表，没有资产表。

迁移顺序：读 `user_version` → 高于 `SCHEMA_VERSION` 时返回明确错误 → 低于时在单事务里执行 `CREATE TABLE IF NOT EXISTS` 建表并把版本推进到当前值；幂等，旧库中的历史遗留表（开发期附件/资产表）不再被读写，数据原样保留。外键启用状态在打开连接时核验。

`create_prompt`、`SaveDraft`、`SavePromptContent` 只写正文并在提交成功后更新内存“已保存”标志。效应须携带目标条目 ID 与编辑修订号；若旧保存结果晚于新修订，只确认其对应版本，不将新内容误标为已保存。数据库失败时保留待保存内容、重试能力和可见错误状态；临时草稿保存失败时 `TempPrompt` 仍在，保存选择器可重试。

## 10. 输入格式与引用语法细则

### 10.1 路径来源

`TerminalEvent::Paste(text)` 只走“纯文本路径/普通文本”两类。对多行路径，按行拆分并仅移除每行的外层换行，不 `trim()` 路径内部或首尾合法空格；空行使整段回退普通文本。`file://` 只接受本机 host（空或 `localhost`），拒绝远程 host、相对路径、NUL、无法解码的百分号序列。Windows 盘符和 UNC 的绝对性按平台路径 API 判定，不用 Unix 风格正则。目录用文件系统元数据判定；图片按文件头签名探测，无法识别为支持的图片时按 file 类型。普通文本即使长得像 `/api/users`，只要不存在也照常插入。

### 10.2 文本写入

占位插入与“引用/路径”都按多个值以单个空格连接；若左邻字符非空白，先加一个空格；末尾加一个空格以便继续输入（对齐参考实现）。前提是不能写入受保护模板元数据范围。已有选区整体替换，光标落在末尾；撤销一次恢复选区原文；取消回滚占位且不留撤销步。路径中包含空格时“路径”模式忠实插入原路径，不能自行拆成多个候选；用户后续如何解释裸路径属于消费者语义。

引用采用 `@[refer-type](path)`。格式化器与解析器共享同一规则并具备往返测试：`decode(encode(path)) == path`。对括号、反斜杠、换行等会破坏分隔符的字符，使用本项目 Markdown 引用语法支持的转义并同步更新解析器（`\`、`(`、`)` 转义；含换行/NUL 的路径禁用引用），绝不只做字符串拼接。保持现有 `@` 提及格式，不将 `@abc` 自动改写成 `@[refer-file]`。

### 10.3 字母候选的范围与展示

先由现有模板块解析器确定光标是否处于**正文范围**；块起止标记行、标题、`{wt:}` 及结构空行均不算正文。块内扫描 `[block_body_start, block_body_end)`；块外扫描整份 prompt。扫描候选时排除代码围栏、无效或未闭合引用、触发词本身及 `@start`/`@end` 等结构标记。提及 `@foo/` 可确定为目录，显示 `[folder]`；一般 `@foo` 无目录信息时显示 `[file]`。同一完整引用多次出现只保留首次，`@abc` 与 `@[refer-file](abc)` 是两个不同候选。

匹配使用 Unicode 安全的字符边界，大小写折叠后评分；至少两个**字符**，而不是两个 UTF-8 字节。`ac` 匹配 `abc` 的顺序为 `a` 后 `c`，不要求相邻。重算顺序为过滤→评分→稳定排序→截取显示上限；键盘上下移动不能因每帧渲染重置高亮。候选来源变更或触发范围变化时重新计算并将高亮夹到有效索引。选中条目用其已保存的完整原文替换触发区间，不能重新格式化后丢失原转义。

## 11. 可观察反馈与验收例子

| 场景 | 预期可见结果 | 关键不变量 |
| --- | --- | --- |
| 粘贴 `/tmp/a.txt` | 先出现纯路径占位，面板默认“插入引用” | 引用改写占位；Esc 回滚占位 |
| 路径粘贴并选路径 | 正文保留 `/tmp/a.txt ` | 一步撤销清空 |
| 粘贴文件夹并选引用 | 正文出现 `@[refer-folder](...)` | 无附件记录、无文件 IO |
| 文件和文件夹混合 | 引用/路径均可用 | 不丢弃任一候选 |
| 粘贴图片文件路径并选引用 | 正文出现 `@[refer-image](path) ` | 外部文件保留原位 |
| 含换行的路径 | 引用项禁用，路径项可用 | 不生成歧义标记 |
| 纯文本 `/api/users` 不存在 | 原文直接插入 | 无面板、无文件 IO |

| 块 A 有 `@abc`，块 B 输入 `ac` | B 不因 A 的引用显示候选 | 不跨块 |

人工验收在可用的 OS 环境验证：终端括号粘贴路径、鼠标选择、Esc 回滚、工作区切换与窄屏布局。自动化测试覆盖纯状态、数据库迁移、平台路径解析与事件路由，不依赖真实桌面会话；用户负责 `cargo run` 下的 TUI 外观与交互确认。

## 12. 具体界面约束

编辑器顶栏沿用现有 Mode、Pin、Undo、Redo、Select All 和保存状态点的位置规则，不设粘贴按钮。

正文里的 `@[refer-*](path)` 引用有独立高亮（整段一个 token，路径不再按行内语法二次解析）：`refer-file` 亮绿下划线、`refer-folder` 橙（Indexed 208）下划线、`refer-image` 亮品红下划线，与 `@` 提及的黄色下划线互不混淆（见 `ui/style.rs` 的编辑器色板 `markdown_*`；它**独立于**阅读渲染的 `md_read_*` GitHub Dark 色板，两者不得复用）。

粘贴二级面板与字母候选面板使用既有命令面板视觉 Token：固定行高、单一选中高亮、同一滚动/鼠标命中逻辑。粘贴面板仅两项（引用/路径），不嵌套第三层。字母候选行左侧保留名称，右端独立 tag 列；tag 过长时裁剪名称，极窄屏时隐藏 tag 而保留行命中和键盘导航。面板超出 prompt 内容区下边界时向上展开；滚动或缩放后重新测量，不能留下旧坐标热点。面板与正文点击按“浮层 > 工具栏 > 正文”的顺序命中。
