# Prompt 粘贴附件与引用快捷输入设计

状态：待用户审核；本文件获确认前不修改功能代码。

## 1. 目标与边界

在 prompt 编辑视图中粘贴路径（终端或系统剪贴板）时，先把纯路径文本写入正文作为占位，再打开紧邻编辑器的二级面板改写格式（对齐 lx-agent 的 `LxMarkdownEditor` / `useAgentInputPaste`）：

1. **插入引用**：把占位文本改写成 `@[refer-file](path)`、`@[refer-folder](path)` 或 `@[refer-image](path)`。
2. **插入路径**：保持占位文本（可直接使用的本机路径）。

取消（Esc/外部点击）回滚到粘贴前文本与光标，不留多余撤销步。系统剪贴板中的位图（截图）不进面板：`Ctrl+V` 读取到的位图落盘登记后直接把 `@[refer-image](path)` 写入正文（见 §14）。

文件类型自动识别：目录为 folder，已识别的图片文件及截图为 image，其余普通文件为 file。多项粘贴只显示一组操作选项，对全部项使用同一种处理方式。不能静默跳过目录。本任务不保存附件列表；图片/文件都以正文引用或路径表达。

新增字母快捷输入：在可编辑正文输入至少 2 个字母/路径字符时，从有效范围内已出现的 `@` 提及和 `@[refer-*]` 引用生成候选。`ac` 可用子序列匹配 `@abc`；确认后用候选的**完整原文**替换 `ac`。候选右端显示来源类型 tag，如 `[file]`、`[folder]`、`[refer-image]`。快捷面板不扫描文件系统，也不产生新引用目标。

本任务不增加 agent 发送流程，不修改 PTY 粘贴语义，不把普通文本的斜杠命令当成文件路径。

## 2. 已确认决策

| 决策 | 规则 |
| --- | --- |
| 正文表达 | 路径/引用/截图全部写入正文；不引入附件列表，路径粘贴不复制外部文件 |
| 持久化 | 只保存正文；截图由 `managed_asset` 登记 + 正文 `@[refer-image]` 引用存活 |
| 截图 | 接受剪贴板位图，落到应用管理目录并登记，再把 `@[refer-image](path)` 写入正文 |
| 清理 | 删除 prompt 后，只清理无 `@[refer-image]` 引用的应用管理截图；绝不删除外部文件 |
| 路径识别 | 仅实际存在的本机绝对路径与 `file://` URI；支持多行；其余文本照常粘贴 |
| 处理选择 | 引用 / 路径；附件类型自动识别，无二次手选（位图不走面板） |
| 快捷候选范围 | 模板块内只读该块已有引用；普通文本区读当前 prompt 全文 |
| 快捷确认 | 候选原文完整替换触发片段，右侧显示类型 tag |
| 平台 | macOS、Windows、Linux；不可读取图片时给明确错误反馈，文本粘贴继续可用 |

## 3. 现状与参考实现

- `src/event/mod.rs` 的 `TerminalEvent::Paste(String)` 在 prompt 聚焦时直接发 `EditorCommand::InsertText`；终端协议只给文本，无法从此事件取到剪贴板位图或文件对象。
- `src/platform/mod.rs` 当前仅实现异步文字写剪贴板，尚无读取文件/位图能力。OS 分支必须继续收口于 `platform/`。
- `src/app/prompt.rs` 持有文本、撤销、面板、已保存状态与修订号；`mention.rs` 管现有 `@` 文件扫描。`Prompt::settle` 的面板优先级为文件提及 > 斜杠 > 块命令。
- `src/ui/prompt.rs` 有共用命令面板渲染，`src/layout.rs` 有工具栏按钮几何与命中；新增入口应复用这两处机制，窄屏隐藏但不能覆盖已有按钮。
- `src/app/update/prompt.rs` 将编辑器内容同步到临时草稿或已保存条目；`src/db/mod.rs` 的 `workspace_prompt` 只有正文；持久层由 `db/service.rs` 执行效应。
- 参考仓库 `lx-agent` 的 `useAgentInputPaste` 在粘贴后给出 upload/reference/path；`createMarkdownReference(type,path)` 产出 `@[refer-${type}](${path})`。`markdownTemplateFileCommands` 的快捷输入最短 2 字符，按名称/路径前缀、包含、子序列排序。

因此 TUI 不能把 Electron 的 ClipboardEvent 原样移植。需将“终端送来的文本”与“用户显式读取系统剪贴板”作为两个入口，最后归一成同一种纯数据粘贴提案。

## 4. 数据模型和不变量

### 4.1 正文表达

本功能不引入附件列表：文件与文件夹以引用标记或纯路径写在正文里，截图以 `@[refer-image](managedpath)` 写在正文里。因此 `Prompt`、`TempPrompt`、`PromptItem` 与数据库都只保留正文，撤销快照也只有文本与光标。

### 4.2 应用管理的截图

截图写入 `config::user_data_root()/attachments/` 下独立文件，开发/生产环境自然隔离；文件名使用安全随机且不重复的资产 `external_id`，扩展名与实际编码一致（`new_external_id` 是时间戳加进程序号，不满足文件名不可预测要求，故另用安全随机源）。平台层读取原始位图，后台任务负责编码和原子落盘（`.tmp-*` → 重命名）；事件循环只接收完成消息。

位图落盘后登记到 `managed_asset`，登记成功才改写正文；登记或写入失败立即删除刚落盘文件并给可见错误，绝不留下半条引用。重启时扫描本应用管理目录，删除数据库中无人引用的登记文件与符合命名规则的孤儿临时文件；扫描只处理本目录内由本功能创建的文件，绝不跟随符号链接或清理任意路径。

垃圾回收判断：先完成数据库更改，再计算所有已保存正文与内存提示词（当前编辑器、各工作区草稿、临时提示词）中的 `@[refer-image]` 引用，最后删除无人引用的 managed 文件。触发点为启动与删除 prompt/文件夹；失败记录 `tracing` 警告并允许下次启动重试。仅凭文件名相似或位于相同目录不足以取得删除权限，须验证路径确属本功能登记的 managed 文件。外部文件永不被删除。

### 4.3 粘贴提案

纯数据 `PasteCandidate` 至少含规范路径、`File|Folder|Image`、来源及展示名；`PasteProposal` 含候选列表、原始选区/光标锚点、prompt 身份与请求代号。异步剪贴板结果只在 prompt 身份、编辑修订和锚点均仍匹配时接受；否则丢弃并清理新建的待处理截图，不能把旧结果插入新工作区。

处理选项与候选类型分开建模，不让 UI 文案决定行为。占位插入先替换原选区并写入纯路径文本（左邻非空白补空格、末尾补空格），随后“引用”改写占位文本、“路径”保持占位文本；“取消”回滚到粘贴前的文本、光标、保存态与修订号，占位插入与格式改写同属**一步撤销**。触碰模板块受保护行（标题行、`{wt:}` 绑定行）时不写入也不打开面板。确认后关闭粘贴面板并保持 prompt 焦点。

## 5. 输入和面板交互

### 5.1 剪贴板入口

剪贴板读取由 `Ctrl+V` / `Cmd+V`（各自可带 `Shift`）触发，不设工具栏按钮；终端把该键用作自身粘贴时不产生按键事件，此时退回终端括号粘贴文本，不构成回退风险。若终端把 `Cmd+V` 处理成“自身粘贴”但剪贴板只有位图，会送来**空括号粘贴**：这种情况改由应用读取系统剪贴板（见 §14.1.3）。读取由事件层异步执行。若为位图，创建 managed 截图后**直接把 `@[refer-image](path)` 写入正文**，不打开面板；若为文件列表/路径文本，逐项校验存在性，保留顺序并去重后进入占位插入 + 提案；若为普通文本，走现有 `InsertText` 路径。`TerminalEvent::Paste(text)` 仍负责终端发来的括号粘贴；对明确且全部有效的路径文本也可进入同一提案流程，其他文本原样插入。读取来源不可用、格式错误或读超时时显示 toast，不能静默吞掉用户的内容。

路径文本须先整体解析：支持单行和逐行 `file://` URI/绝对路径，逐项 URI 解码；任何一项不是存在的本机路径时，整段按普通文本处理，不做部分转换。不得仅因首字符为 `/` 或含图片扩展名就弹出面板。保持路径中的空格和非 ASCII 字符；引用标记中的 `)` 等分隔符必须按本项目 Markdown 引用语法处理，不能生成截断或歧义文本。若当前语法无法无损表达某路径，应禁用引用选项并明确提示，保留路径选项。

### 5.2 二级选择面板

面板锚定当前 prompt 光标行，屏幕边界不足时向上展开；沿用现有命令面板的键盘和鼠标命中模式。`Up/Down` 改变高亮，`Enter` 确认，`Esc` 取消；外部点击关闭且不穿透编辑区。面板展示操作名与当前候选数、文件/图片/目录类别。选择期间捕获或取消其他互斥面板；优先级为粘贴选择 > 现有 `@` 提及 > 字母快捷 > 斜杠 > 块命令。面板关闭后才重算被压制的其他面板。

截图位图没有原始路径，位图不走面板，直接以刚创建的 managed 路径写入引用。普通外部文件的占位文本就是源路径，引用改写也使用源路径。

正文中的 `@[refer-*](path) ` 与 `@文件 ` 提及同构：光标紧跟尾随空白时一次 Backspace 删除整段标记（含尾随空白），单步可撤销；无尾随空白或标记非法时退化为逐字符删除。

### 5.3 字母快捷输入

触发词只取光标前、单词边界后的 2 个及以上常见路径字符，前缀为 `@`、位于已有 `@[refer-*]` 标记内部、代码围栏、结构元数据行或模板保护区时不触发。触发源仅为当前 prompt **正文已出现**的 `@` 提及、`@[refer-file/folder/image]` 引用。

光标在模板块正文中：只收集该块中的引用，不跨块；光标在普通文本区：收集整个 prompt 正文中的引用。重复的完整标记只展示一次，保留首次出现顺序作同分排序。输入 `ac` 能以不连续子序列匹配 `abc`；优先级为名称完全匹配、名称前缀、路径前缀、名称包含、名称子序列、路径包含。无候选不显示。确认后完整替换触发词，作为一个撤销步；Esc 只关闭本轮面板，继续编辑后再重算。

右侧 tag 依据引用的实际语法/候选类型生成：`@` 文件候选 `[file]`，可确定目录时 `[folder]`；`@[refer-file]`、`@[refer-folder]`、`@[refer-image]` 分别显示 `[refer-file]`、`[refer-folder]`、`[refer-image]`。tag 使用固定右侧空间，长路径从中间或末尾截断，不能挤出面板或改变命中行宽。窄屏仍应可选，tag 放不下时优先保留引用名称与高亮。

## 6. 模块归属

| 模块 | 责任 |
| --- | --- |
| `platform/` | 各 OS 剪贴板文件/位图读取；返回平台中立数据，不持有 AppState |
| `event/` | 发起后台读取/编码、请求代号与结果路由、错误 toast；不阻塞事件循环 |
| `app/prompt/` | 粘贴占位插入、面板改写/回滚与快捷候选的纯状态转换；撤销、修订、面板互斥 |
| `app/markdown/` | 现有引用/模板块语法的复用或最小扩展；引用解析、格式化与整段删除为纯函数 |
| `app/update/` | 当前 prompt、临时草稿和已保存条目的正文同步及效应出箱 |
| `db/` | v2 迁移、正文读写与 `managed_asset` 登记/查询 |
| `ui/`, `layout.rs` | 只读绘制、工具栏几何、二级面板与鼠标命中；可见文案放 `ui/text.rs` |

不为此任务改动 `tui/` 的终端恢复顺序。若使用第三方剪贴板/编码库，执行阶段先通过 Context7 核对 API 与平台能力，再选依赖；不能把 OS 分支放到 `event/` 或 `app/`。

## 7. 失败语义与验收

- 已保存 prompt 和临时草稿在切换工作区/编辑目标后，正文（含引用）随原 prompt；重启后正文正确恢复。
- 图片粘贴的读取、编码、保存、取消和删除可预测；失败不留半条引用，也不修改正文。
- 外部文件永不被删除；managed 截图只有在所有保存记录、正文引用和内存草稿均不使用时清理。
- 旧 v1 数据库无损升级，旧 prompt 正文不变；迁移和保存失败保留可恢复状态并向用户反馈。
- 已有 `@` 扫描、斜杠和块命令的键盘/鼠标行为不回退；新面板在窄屏和工作区切换时不漂移。
- TUI 外观与真实系统剪贴板需要用户运行 `cargo run` 检查；自动化验证覆盖纯状态、数据库迁移/级联、平台格式解析和事件路由。

## 8. 精确状态流

### 8.1 现有状态通路与新增字段归属

当前屏幕中的编辑器是 `AppState.prompt: Prompt`；切换工作区时，`src/app/update.rs::load_displayed_draft` 从工作区的 `PromptDraft { editor, root }` 取出完整编辑器。当前条目内容通过 `commit_prompt_buffer` 写回 `TempPrompt.content` 或 `PromptItem.content`，再产生 `SavePromptContent` 效应。`SaveDraft` 效应先创建数据库记录，成功后 `finish_draft_save` 才移除临时项并绑定新条目。正文（含引用）必须遵循同样通路，不能只存在屏幕中的 `Prompt`。

字段放置规则：

| 位置 | 持有内容 | 失效时机 |
| --- | --- | --- |
| `Prompt` | 当前正在编辑的正文、字母面板与粘贴面板的纯状态、修订号 | 切换编辑目标时提交并重建；切换工作区时随整个 `PromptDraft.editor` 停泊 |
| `TempPrompt` | 临时草稿正文 | 用户删除临时项，或 `SaveDraft` **成功**后移除 |
| `PromptItem` | 已保存条目的正文缓存 | 树重载时从数据库重建 |
| `PasteState` | 在途读取请求、占位插入现场与面板候选 | 确认/取消/失效或新请求覆盖；占位文本本身进撤销快照，其余不进数据库 |
| 数据库 | 已保存条目的正文与 `managed_asset` 登记 | 删除记录后仍需经过正文引用扫描与文件清理 |

`Prompt::set_text` 重置文本、编辑历史与面板状态；加载条目正文即加载全部内容。`commit_prompt_buffer` 只比较正文。临时项进入/离开编辑器时，`TempPrompt` 与 `Prompt` 间复制正文。

### 8.2 从输入到确认的顺序

```text
Ctrl+V / 终端 Paste(text)
  -> 平台读取或文本路径解析（后台）
  -> 返回候选 + 目标 Prompt ID + 请求代号 + 原编辑修订/选区
  -> 校验目标仍是当前编辑器且修订未变化
  -> 按登记锚点占位插入纯路径文本（一次撤销步）并打开面板
  -> 用户选引用（改写占位）/ 路径（保持占位），或取消（回滚占位）
  -> 一次状态转换 + 一步撤销 + 更新修订号
  -> 临时项写回内存 / 已保存项排队同一保存效应
  -> 数据库成功后确认保存状态，再异步回收无人引用的 managed 资产
```

`Ctrl+V` 读取期间可显示非阻塞加载状态；重复触发只保留最新请求。鼠标点击工具栏本身不得先把 prompt 焦点转给窗格。终端粘贴为普通文本时仍是当前同步编辑行为，不为所有粘贴强制起后台任务。用户在后台读取期间输入、移动光标、改变选区、切换条目/工作区或退出，旧结果一律失效；若后台已生成 managed 文件，交给安全清理队列。结果处理不得凭 `PaneId` 单独认定目标，因为同一个编辑器对象可能已绑定另一条目，还需目标 `PromptEditing` 标识与请求代号。

### 8.3 面板状态机

| 当前状态 | 事件 | 下个状态 | 文本副作用 |
| --- | --- | --- | --- |
| Idle | 有效路径/位图请求 | Reading | 无 |
| Reading | 读到候选且目标仍匹配 | Choosing | 无 |
| Reading | 空剪贴板/平台错误 | Idle | 无；显示错误 toast |
| Reading | 新请求/目标变化 | Reading 或 Idle | 旧请求失效；清理旧待处理文件 |
| Choosing | 上/下或悬停 | Choosing | 只改高亮 |
| Choosing | Enter/点击可用项 | Idle | 引用改写占位文本 / 路径保持占位文本 |
| Choosing | Esc/外部点击/失焦/目标变化 | Idle | 回滚占位插入（含撤销步），正文回到粘贴前 |
| Choosing | 新粘贴 | Reading | 先取消旧提案，再处理新输入 |

禁用项不能成为键盘高亮或点击确认目标；两项都不可用时直接关闭（占位文本按路径保留）。`Ctrl+Q` 始终维持应用级退出优先级。面板打开时可用的编辑命令仅导航、确认、取消；其他按键按现有面板策略吞掉，不写入 PTY。关闭后重新调用既有面板收敛函数，保证 `@`、斜杠和块命令不会同时绘制。

## 9. 存储格式、迁移和原子性

数据库 `SCHEMA_VERSION = 3`。`workspace`、`workspace_folder`、`workspace_prompt` 均使用自增 `id INTEGER` 作内部行标识、`external_id TEXT NOT NULL UNIQUE` 作稳定跨表标识；`workspace_prompt.folder_id` 与 `workspace_id` 都是指向其他表 `external_id` 的 `TEXT` 外键。实施时将 v1 建表保留为历史步骤，新增**独立**的 v2 迁移，不能把 v2 表直接塞进 v1 后再声称完成升级。v2 表按同一约定定义为：

```sql
CREATE TABLE managed_asset (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    external_id TEXT NOT NULL UNIQUE,
    path TEXT NOT NULL UNIQUE,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
```

字段语义：`id` 是数据库内部持久行号；`external_id` 是安全随机资产标识（与文件名 stem 一致）用于稳定标识；`path` 唯一，指向管理目录下的实际文件；`created_at`/`updated_at` 沿用 `datetime('now')`。登记只表示“这是本应用可管理、可回收的资产”，不表示任何 prompt 正在引用它；引用关系只存在于正文。

迁移顺序：读 `user_version`；0→1 建旧表、1→2 建 `managed_asset`、2→3 折叠开发期 v2 建过的附件表（仅当旧表存在时把资产登记搬进 `managed_asset` 再删除附件表，附件功能已移除）；每步在 SQLite 事务中完成建表与版本推进。版本高于程序支持值时返回明确错误。外键启用状态须在打开连接时核验。

`create_prompt`、`SaveDraft`、`SavePromptContent` 只写正文并在提交成功后更新内存“已保存”标志。效应须携带目标条目 ID 与编辑修订号；若旧保存结果晚于新修订，只确认其对应版本，不将新内容误标为已保存。数据库失败时保留待保存内容、重试能力和可见错误状态；不能沿用“先标记已保存，再忽略写入错误”的时序。临时草稿保存失败时，`TempPrompt` 仍在，保存选择器可重试。

截图原子落盘后以安全随机 `external_id` 登记到 `managed_asset`，登记成功才改写正文；登记或写入失败立即删除刚生成的文件。若进程在落盘与登记之间退出，启动扫描要识别并清理该目录内符合本功能命名规则的孤儿临时文件。

删除 managed 文件分两个阶段：数据库事务提交后，把候选资产 ID 交给清理器；清理器查询所有已保存正文中的引用以及内存中的临时草稿与当前编辑器，再决定是否删除实际文件及登记；引用关系只在正文里。重启清理只遍历 `attachments/` 下符合该规则的普通文件。路径比较使用规范化后的完整路径，不能用字符串前缀判断目录归属（例如 `attachments-old/` 不能算本目录）。删除前再次检查目标不是符号链接且仍位于管理目录。数据库删除成功、文件删除失败时保留登记并允许下次启动重试；反向顺序绝不允许。

## 10. 输入格式与引用语法细则

### 10.1 来源优先级

显式 `Ctrl+V` 读取按顺序识别：平台提供的文件列表 → 位图 → 纯文本路径 → 普通文本。位图不进入面板，直接写入 `@[refer-image]` 引用。若剪贴板同时含图片和文本，优先处理真实文件/位图，避免将截图说明文本误当路径。终端 `Paste(String)` 只能走“纯文本路径/普通文本”两类；无权推断位图。空内容不修改 prompt。图片格式探测在后台进行，无法识别为支持的图片时按 file 类型；目录用文件系统元数据判定。

对多行路径，按行拆分并仅移除每行的外层换行，不 `trim()` 路径内部或首尾合法空格；空行使整段回退普通文本。`file://` 只接受本机 host（空或 `localhost`），拒绝远程 host、相对路径、NUL、无法解码的百分号序列。Windows 盘符和 UNC 的绝对性按平台路径 API 判定，不用 Unix 风格正则。校验的是粘贴当时的存在性；确认时文件可能已被外部删除，引用/路径写入前再次检查并提示，不留下半成品。普通文本即使长得像 `/api/users`，只要不存在也照常插入。

### 10.2 文本写入

占位插入与“引用/路径”都按多个值以单个空格连接；若左邻字符非空白，先加一个空格；末尾加一个空格以便继续输入（对齐参考实现）。前提是不能写入受保护模板元数据范围。已有选区整体替换，光标落在末尾；撤销一次恢复选区原文；取消回滚占位且不留撤销步。路径中包含空格时“路径”模式忠实插入原路径，不能自行拆成多个候选；用户后续如何解释裸路径属于消费者语义。

引用采用 `@[refer-type](path)`。格式化器与解析器应共享同一规则并具备往返测试：`decode(encode(path)) == path`。对括号、反斜杠、换行等会破坏分隔符的字符，要么使用已有 Markdown 语法可支持的转义并同步更新解析器，要么禁用该候选的“引用”并说明原因；绝不只做字符串拼接。保持现有 `@` 提及格式，不将 `@abc` 自动改写成 `@[refer-file]`。

### 10.3 字母候选的范围与展示

先由现有模板块解析器确定光标是否处于**正文范围**；块起止标记行、标题、`{wt:}` 及结构空行均不算正文。块内扫描 `[block_body_start, block_body_end)`；块外扫描整份 prompt。扫描候选时排除代码围栏、无效或未闭合引用、触发词本身及 `@start`/`@end` 等结构标记。提及 `@foo/` 可确定为目录，显示 `[folder]`；一般 `@foo` 无目录信息时显示 `[file]`。同一完整引用多次出现只保留首次，`@abc` 与 `@[refer-file](abc)` 是两个不同候选。

匹配使用 Unicode 安全的字符边界，大小写折叠后评分；至少两个**字符**，而不是两个 UTF-8 字节。`ac` 匹配 `abc` 的顺序为 `a` 后 `c`，不要求相邻。重算顺序为过滤→评分→稳定排序→截取显示上限；键盘上下移动不能因每帧渲染重置高亮。候选来源变更或触发范围变化时重新计算并将高亮夹到有效索引。选中条目用其已保存的完整原文替换触发区间，不能重新格式化后丢失原转义。

## 12. 具体界面约束

编辑器顶栏沿用现有 Mode、Pin、Undo、Redo、Select All 和保存状态点的位置规则。粘贴入口不再是工具栏按钮（见 §14）；`layout.rs` 的按钮枚举、绘制与鼠标命中保持一致，不新增隐藏按钮。

粘贴二级面板与字母候选面板使用既有命令面板视觉 Token：固定行高、单一选中高亮、同一滚动/鼠标命中逻辑。粘贴面板仅两项（引用/路径），不嵌套第三层。字母候选行左侧保留名称，右端独立 tag 列；tag 过长时裁剪名称，极窄屏时隐藏 tag 而保留行命中和键盘导航。面板超出 prompt 内容区下边界时向上展开；滚动或缩放后重新测量，不能留下旧坐标热点。面板与正文点击按“浮层 > 工具栏 > 正文”的顺序命中。

## 14. 实施后修订（用户确认，覆盖上文冲突处）

### 14.1 第一轮：入口与选项收敛

1. **移除 prompt 顶栏粘贴按钮**：`PromptToolbarButton::Paste`、对应几何/工具提示/文案与事件分支全部删除；工具栏恢复 Mode/Pin/Undo/Redo/Select All/保存点，钉住按钮最小宽度随之从 25 列回到 21 列。
2. **移除粘帖面板的 “Upload as attachment”**：`PasteAction` 只保留 `Reference`/`Path`，面板两行；目录仍可引用为 `@[refer-folder](...)`，只有路径无法无损表达（含换行/NUL）时才禁用引用。
3. **`Ctrl+V` 直接粘贴剪贴板图片**：位图必须由应用自读系统剪贴板（终端括号粘贴只承载文本），入口键为 `Ctrl+V`（`Ctrl+Shift+V` 同义，`Ctrl+Alt+V` 不触发）；仅在 prompt 聚焦且编辑视图生效，树视图吞掉按键。
   - `Cmd+V`（Super+V）在路由层同样接受（`input::route` 同时匹配 CONTROL/SUPER）；能否生效取决于终端是否把该键下发给应用：支持 kitty 键盘协议的终端（kitty/WezTerm/Ghostty 等，本项目已 push `DISAMBIGUATE_ESCAPE_CODES`）会下发 Super+V；Terminal.app 与 iTerm2 默认把 `Cmd+V` 绑定为自身粘贴，需要在终端里改键（或直接把该键映射为发送 ``）才能生效。
   - 回退：终端自身粘贴但只承载位图时会发出**空括号粘贴**，此时应用改为自读系统剪贴板，使 `Cmd+V` 截图在支持该行为的终端上仍可用；不支持（完全不发事件）时不触发。
   - 已知限制：Windows Terminal / VS Code 终端默认把 `Ctrl+V` 用作自身粘贴，不会下发按键（此时退回终端粘贴文本，无回退风险）；SSH 会话读到的是远端剪贴板。
4. **正文引用的快捷删除**：新增 `markdown::reference_deletion_range`，与 `mention_deletion_range` 同构——光标紧跟 `@[refer-*](path) ` 尾随空白时一次 Backspace 删除整段标记（含尾随空白），单步可撤销；围栏内标记不参与。

### 14.2 第二轮：占位插入 + 面板改写，彻底移除附件（当前实现）

对齐 lx-agent（`LxMarkdownEditor` 的粘贴即写引用、`useAgentInputPaste` 的占位插入 + 面板改写）。本节为准，§1/§2/§4/§5/§8/§9/§11/§12 已按本节改写：

1. **路径粘贴改为“先占位、后面板改写”**：接受读取结果时按登记锚点写入纯路径文本（左邻非空白补空格、末尾补空格），面板默认高亮“插入引用”；选引用则把该段占位文本改写成 `@[refer-*](path)`，选路径保持占位文本；`Esc`/外部点击/再次粘贴回滚占位插入并恢复保存态与修订号（不留多余撤销步）；占位插入与格式改写同属**一步撤销**。
2. **位图直接写正文引用**：`Ctrl+V` 读到剪贴板位图 → 落盘 managed 临时文件 → 登记 `managed_asset` → 在锚点插入 `@[refer-image](managed路径) `（一次可撤销编辑）。不弹面板、不显示任何附件 item；登记或写入失败（含受保护行）删除刚落盘文件并 toast。

4. **回收触发点**：启动扫描与删除 prompt/文件夹；正文引用移除后的回收推迟到下一次触发（不留后台轮询）。
